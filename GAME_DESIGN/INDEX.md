# 게임 기획 색인

> 요약: 작업 주제로 필요한 문서만 찾아 읽는 기획 진입점
> 상태: 확정
> 연관: [[vision]], [[pillars]], [[workflow]]

- 필요한 주제의 문서만 열고, 규칙이 연동되는 경우 연관 링크를 추가 확인한다.
- 문서 상태와 구현 여부는 다르다. 테스트 수치·미구현·기존 확정 항목은 본문 표기를 따른다.
- 위키 링크는 같은 폴더의 파일명을 가리킨다. 일반 Markdown 뷰어용 파일 링크도 함께 제공한다.
- 거주 시설 수치 변경 예: [[buildings]] → 필요할 때 [[population]] / [[construction]]. 연구 변경 예: [[research]] → 필요한 [[researchscreen]] / [[saves]].
