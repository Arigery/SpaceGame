# 일반 이상현상

> 요약: 성계별 배정, 고정 결과와 적대 세력
> 상태: 논의중
> 연관: [[stories]], [[signals]], [[economy]]


### 탐사 이상현상 이벤트 — 1차 테스트

- 100성계의 이상현상 60슬롯 중 15개에 신규 고정 결과를 배정한다. 신규 풀은 긍정 60%, 일반 부정 20%, 적대 세력 16%, 파괴 후보 4%를 시험 가중치로 사용한다. 파괴 사건은 은하당 최대 1건이다. 탐사선의 기존 조사 기록·연쇄 진행은 유지하고 해당 함선만 제거한다. 재생산은 [[shipyards]]를 따른다. 불모 신규 사건은 긍정만 배정하며 기존 선택형은 모든 결과가 이득인 경우에만 유지한다.
- 광물·가스에서 행성 유형에 맞는 사건이 없거나 희귀 상한에 닿으면 긍정·일반 부정(3:1)에서 다시 고른다. 적대 세력은 은하당 최대 2곳이다. 시작 성계와 초기 개척 보장 성계를 제외한다. 기존 저장의 배정은 유지한다.
- 신규 효과와 가중치는 `data/exploration.json`의 `anomalyExpansion`에서 관리한다. 신규 사건은 즉시 한 번만 처리하며, 장비 파손·정신 교란은 해당 탐사선의 다음 턴 행동력만 0으로 만든다. 즉시 자원 차감은 재고 0을 하한으로 한다.
- 정보 선택은 일반 항로 거리 2 이내의 지도 공개·미방문 성계에 한정한다. 유형별 행성 수만 공개한다. 매몰된 관측 시설은 시드로 1곳을 자동 선택하며, 후보가 없으면 연구력 +10을 지급한다.
- 적대 무인 함대·생명체는 기본 초계함 1척 성능을 사용한다. 해당 성계에서 이동·증원·재생성하지 않으며 활성 상태에서는 개척할 수 없다. 전투로 제거한 문명은 연구력 +10을 한 번 받는다.
- 최초 조우는 탐사 완료 후 가장 낮은 성계 ID의 안전한 인접 성계로 행동력 소모 없이 강제 후퇴한다. 안전한 곳이 없으면 실종되어 명령할 수 없으며, 기존 긴급 워프 거리별 기간이 지나면 가동 중인 아군 조선소로 복귀한다. 복귀할 조선소가 없으면 실종 상태를 유지한다.
- 고정 결과와 선택 확정 결과는 중앙 카드에 표시한다. 자원 보상은 아이콘과 실제 정산 수치로 제시하며, ‘보상 획득’ 또는 ‘결과 확인’을 눌러 닫는다. 확인은 이미 적용된 효과를 중복 지급하지 않는다. 활성 적대 성계에는 지도·성계 경고를 표시한다.
- 실종 탐사선의 복귀 예정 조선소와 남은 턴은 알림에서 확인한다. 파괴 활성화 이후 고정 시드 시험 결과는 [[validation]]을 따른다.

- 성계 단위 일반 이상현상은 짧은 이상현상 60%, 희귀 특수 분류 3%, 이벤트 없음 37%로 배정한다. 기본 100개 성계(시작 성계 포함)는 60/3/37개다. 시작 성계는 이벤트 없음이며 작은 지도에서는 최대 나머지 방식으로 정수 배정한다. 기존 통합 확률은 폐기한다.
- 거주 가능 행성 탐험은 각 행성마다 65% 확률로 독립 판정한다. 성계 이상현상 배정과 별개의 시드 난수를 사용하며, 거주 가능 행성 2개인 성계는 각각 발생할 수 있다. 전체 발생 개수를 고정하지 않는다. 이미 탐사 완료된 시작 행성에는 소급 팝업을 띄우지 않는다.
- 지도 생성 난수와 분리된 시드 난수로 배정 계획을 만들고 저장한다. 최초 대상 탐사 때 해당 성계의 이벤트를 확정하고, 지정된 행성을 탐사했을 때 발생한다. 탐사 순서가 달라도 배정과 선택지 효과는 같다. 선택에 따른 결과 차이는 유지한다.
- 성계당 일반 이상현상은 최대 1개다. 이상현상은 광물·가스·불모 중 적합한 행성 하나에 배정한다. 거주 가능 행성 이벤트는 이 제한과 무관하며 행성마다 최대 1개다. 조건을 만족할 성계가 부족하면 초과 할당은 일반 탐험으로 재배정한다. 희귀는 분류만 저장하고 팝업·보상은 없다.
- 광물·가스 이상현상의 성격 목표는 긍정 40%, 부정 25%, 선택 35%다. 불모는 부정형만 제외하고 기존 긍정:선택 가중치 40:35를 정규화해 약 53.33%:46.67%로 배정한다. 유형별 정수 배정의 반올림 오차를 허용한다. 선택형은 두 선택지 중 하나만 적용한다.

| 행성 | 이벤트 | 효과 — 1차 테스트 수치 |
| --- | --- | --- |
| 광물 | 초고밀도 광맥 발견 | 해당 광산 생산량 영구 +10% |
| 광물 | 불안정한 지각 | 진행 중 또는 다음 광산 공사 1회에 +2턴. 이후 강화에는 반복 적용하지 않음 |
| 광물 | 희귀 금속층 발견 | 즉시 광물 +20 / 해당 광산 생산량 영구 +5% 중 선택 |
| 가스 | 고에너지 가스층 | 해당 채집소 생산량 영구 +10% |
| 가스 | 대기 폭풍 | 해당 채집소 가동 3턴 동안 생산량 −20% |
| 가스 | 비정상적인 에너지 반응 | 즉시 에너지 +20 / 연구력 +15 중 선택 |
| 불모 | 지하 광물 매장 | 즉시 광물 +15 |
| 불모 | 특이한 암석 구조 | 즉시 연구력 +15 / 공개된 미방문 성계 1곳의 행성 구성 중 선택 |
| 불모 | 결정질 표본 발견 | 즉시 연구력 +10 |
| 불모 | 매몰된 에너지 전지 | 즉시 에너지 +15 |
| 불모 | 버려진 보급 용기 | 즉시 소비재 +10 / 신소재 +5 중 선택 |

- 추가 이상현상도 기존 효과 종류를 사용하며 아래 수치는 1차 테스트 기준이다.

| 행성 | 이벤트 | 효과 |
| --- | --- | --- |
| 광물 | 노출된 광석 지대 | 즉시 광물 +20 |
| 광물 | 오래된 지층 표본 | 연구력 +15 / 신소재 +5 중 선택 |
| 가스 | 대전된 가스 구름 | 즉시 에너지 +20 |
| 가스 | 안정적인 대기 흐름 | 해당 채집소 영구 생산량 +5% / 에너지 +20 중 선택 |
| 불모 | 충돌 유리층 발견 | 즉시 신소재 +5 |
| 불모 | 운석 파편 지대 | 광물 +20 / 연구력 +15 중 선택 |

- 기존 풀은 불모 7종과 광물·가스 각 5종으로 총 17종이다. 구형 불모 자기장 교란은 배정에서 제외하고 이전 저장의 미확인 건은 지하 광물 매장으로 전환한다. 신규 가스 자기장 교란과 이미 적용된 결과는 영향받지 않는다.

- 단서 보상으로 얻는 유형별 행성 수는 지도 호버로 확인한다. 이름·진입 권한·탐험·행성 탐사 완료 판정은 유지한다. 후보가 없는 기존 선택형 단서 사건은 나머지 선택지의 보상을 지급한다.
- 생산·공사 효과는 해당 행성의 `explorationEffects`에 저장한다. 시설이 없을 때도 유지한다. 폭풍 기간은 소유한 시설이 실제 턴 생산을 정산한 뒤 감소하며, 건설 대기·건설 중·미개척 기간에는 줄지 않는다. 완공 턴에는 아직 생산하지 않으므로 다음 턴부터 센다. 불모 행성 개발은 계속 불가능하다.
- 즉시 자원, 영구 생산 보정, 기간제 생산 보정, 일회 공사 지연, 행동력 소모, 정보 단서를 별도 효과 종류로 관리한다. 생산량 표시와 실제 자원 정산은 같은 보정 함수를 사용한다. 건설 지연은 비용을 바꾸지 않으며 착공 시 공사 타이머에 저장한다.
- 거주 가능 행성의 임시 팝업은 아래 데이터 기반 조사 이벤트로 대체한다. 독립 발생 확률 65%와 성계 이상현상 배정은 그대로 유지한다.
- 일반 탐험에는 팝업이 없다. 이상현상은 기존 다크 SF 팝업을 사용하고 설명·효과를 표시한다. 결과 적용 후 확인 창과 짧은 진행 기록을 제공한다. 선택하지 않은 채 닫아 이벤트를 버릴 수 없으며, 결과 적용은 한 번만 가능하다.
- 같은 성계의 이상현상과 거주 가능 행성 이벤트는 각각의 상태를 보존한 채 하나씩 순차 표시한다. 유적은 [[relics]], 블랙홀은 [[blackholes]]의 규칙을 따른다. 튜토리얼에는 새 이벤트를 적용하지 않는다.
- 성계 배정 계획, 성계별 확정 이벤트, 행성별 `habitableEvent` 판정, 미선택 상태, 선택 결과, 결과 확인 대기 및 행성 효과를 저장한다. 불러오기 후 미선택/확인 대기 팝업을 이어 표시하고 효과는 중복 적용하지 않는다. 이벤트 시스템 이전 저장에서 이미 전체 또는 일부 행성을 탐사한 성계에는 일반 이상현상을 소급 발생시키지 않는다. 행성 이벤트는 이미 탐사한 행성에는 소급하지 않는다. 통합 확률 버전 저장의 이미 발생한 이벤트·선택 결과·효과는 유지하고, 미발생 배정만 새 규칙으로 전환한다. 이전 거주 가능 이벤트의 미확인 팝업은 해당 행성으로 옮겨 이어 표시한다.
- 데이터는 `data/exploration.json`, 규칙은 `src/exploration.js`에서 관리한다. 이번 비율·효과 수치는 최종 밸런스가 아닌 1차 테스트 기준이다.
