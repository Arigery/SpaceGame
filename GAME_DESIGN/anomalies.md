# 일반 이상현상

> 요약: 성계별 배정과 행성 유형별 17종 이벤트
> 상태: 논의중
> 연관: [[stories]], [[signals]], [[economy]]


### 탐사 이상현상 이벤트 — 1차 테스트

- 성계 단위 일반 이상현상은 짧은 이상현상 60%, 희귀 특수 분류 3%, 이벤트 없음 37%로 배정한다. 기본 100개 성계(시작 성계 포함)는 60/3/37개다. 시작 성계는 이벤트 없음이며 작은 지도에서는 최대 나머지 방식으로 정수 배정한다. 기존 통합 확률은 폐기한다.
- 거주 가능 행성 탐험은 각 행성마다 65% 확률로 독립 판정한다. 성계 이상현상 배정과 별개의 시드 난수를 사용하며, 거주 가능 행성 2개인 성계는 각각 발생할 수 있다. 전체 발생 개수를 고정하지 않는다. 이미 탐사 완료된 시작 행성에는 소급 팝업을 띄우지 않는다.
- 지도 생성 난수와 분리된 시드 난수로 배정 계획을 만들고 저장한다. 최초 대상 탐사 때 해당 성계의 이벤트를 확정하고, 지정된 행성을 탐사했을 때 발생한다. 탐사 순서가 달라도 배정과 선택지 효과는 같다. 선택에 따른 결과 차이는 유지한다.
- 성계당 일반 이상현상은 최대 1개다. 이상현상은 광물·가스·불모 중 적합한 행성 하나에 배정한다. 거주 가능 행성 이벤트는 이 제한과 무관하며 행성마다 최대 1개다. 조건을 만족할 성계가 부족하면 초과 할당은 일반 탐험으로 재배정한다. 희귀는 분류만 저장하고 팝업·보상은 없다.
- 광물·가스 이상현상의 성격 목표는 긍정 40%, 부정 25%, 선택 35%다. 불모는 부정형만 제외하고 기존 긍정:선택 가중치 40:35를 정규화해 약 53.33%:46.67%로 배정한다. 유형별 정수 배정의 반올림 오차를 허용한다. 선택형은 두 선택지 중 하나만 적용한다.

- 불모 이벤트는 긍정형 4종·선택형 3종의 총 7종이다. 광물·가스는 각각 5종이며, 활성 이상현상은 총 17종이다. 자기장 교란은 새 배정에서 제외한다. 이전 저장의 아직 미확인인 자기장 교란은 지하 광물 매장으로 전환하고, 이미 적용된 결과는 소급 변경하지 않는다.

- 단서는 아직 단서를 얻지 않은 미탐험 이웃 중 시드로 선택한다. 위치는 기존 항로 공개로 이미 보이므로 행성 유무 정보만 결과 창·기록에 제공한다. 이름·진입 권한·탐험·행성 탐사 완료 판정은 변경하지 않는다. 적합한 이웃이 없으면 추가 단서 없음을 표시하며 대체 보상은 없다.
- 생산·공사 효과는 해당 행성의 `explorationEffects`에 저장한다. 시설이 없을 때도 유지한다. 폭풍 기간은 소유한 시설이 실제 턴 생산을 정산한 뒤 감소하며, 건설 대기·건설 중·미개척 기간에는 줄지 않는다. 완공 턴에는 아직 생산하지 않으므로 다음 턴부터 센다. 불모 행성 개발은 계속 불가능하다.
- 즉시 자원, 영구 생산 보정, 기간제 생산 보정, 일회 공사 지연, 행동력 소모, 정보 단서를 별도 효과 종류로 관리한다. 생산량 표시와 실제 자원 정산은 같은 보정 함수를 사용한다. 건설 지연은 비용을 바꾸지 않으며 착공 시 공사 타이머에 저장한다.
- 거주 가능 행성의 임시 팝업은 아래 데이터 기반 조사 이벤트로 대체한다. 독립 발생 확률 65%와 성계 이상현상 배정은 그대로 유지한다.
- 일반 탐험에는 팝업이 없다. 이상현상은 기존 다크 SF 팝업을 사용하고 설명·효과를 표시한다. 결과 적용 후 확인 창과 짧은 진행 기록을 제공한다. 선택하지 않은 채 닫아 이벤트를 버릴 수 없으며, 결과 적용은 한 번만 가능하다.
- 기존 유적 발견 팝업은 먼저 처리하고 새 이벤트는 기존 팝업이 닫힌 뒤 표시한다. 같은 성계의 이상현상과 여러 거주 가능 행성 이벤트도 각각의 상태를 보존한 채 하나씩 순차 표시한다. 유적·블랙홀 발견·연결·이동 규칙은 유지한다. 튜토리얼에는 새 이벤트를 적용하지 않는다.
- 성계 배정 계획, 성계별 확정 이벤트, 행성별 `habitableEvent` 판정, 미선택 상태, 선택 결과, 결과 확인 대기 및 행성 효과를 저장한다. 불러오기 후 미선택/확인 대기 팝업을 이어 표시하고 효과는 중복 적용하지 않는다. 이벤트 시스템 이전 저장에서 이미 전체 또는 일부 행성을 탐사한 성계에는 일반 이상현상을 소급 발생시키지 않는다. 행성 이벤트는 이미 탐사한 행성에는 소급하지 않는다. 통합 확률 버전 저장의 이미 발생한 이벤트·선택 결과·효과는 유지하고, 미발생 배정만 새 규칙으로 전환한다. 이전 거주 가능 이벤트의 미확인 팝업은 해당 행성으로 옮겨 이어 표시한다.
- 데이터는 `data/exploration.json`, 규칙은 `src/exploration.js`에서 관리한다. 이번 비율·효과 수치는 최종 밸런스가 아닌 1차 테스트 기준이다.
