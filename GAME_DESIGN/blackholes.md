### 3.4 블랙홀

- 블랙홀 자체를 탐사하면 성계 전체 탐사가 끝나기 전에도 이용할 수 있다.
- 탐사 완료 시 반대편의 블랙홀과 항성만 완료 상태로 기록하고 성계 이름을 공개한다. 반대편 행성·고대 오브젝트는 미탐사로 유지하며 성계 전체를 완료 처리하지 않는다.
- 반대편 항성만 확인한 상태에서는 그곳의 거주 가능 행성 유무를 지도 표식으로 공개하지 않는다. 탐사선이 실제 도착하면 행성 구성을 확인한다.
- 탐사한 블랙홀 우클릭 메뉴와 함선 패널에서 블랙홀 이동을 실행한다. 행동력은 1이다.
- 블랙홀 이동 연출은 출발 블랙홀 접근 → 축소·소멸 → 반대편 블랙홀 출현 → 출구 근처 정지 순서다. 빠른 이동은 출구 근처에 즉시 배치한다.
