## 1단계 구현 범위
- 기존 실행 파일에 공통 전투 모듈을 포함한다. 별도 프로토타입은 만들지 않는다.
- [[shipdesigns]]의 설계, [[shipyards]]의 생산·수리·증원으로 구성한 함대는 [[fleets]]의 공동 이동과 도착 교전에 참가할 수 있다. 전투 화면은 [[combatui]], 고정 적 함대를 사용하는 시험은 [[combattest]]를 따른다.
- 캠페인의 자동 적 진영 생성과 전략은 후속 범위다. 탐사선·개척선은 [[scoutdanger]]의 별도 규칙을 따른다.
- 함체 해금 순서는 아래 표에 따르며, 연구 조건과 생산 비용은 [[shipyards]]에서 관리한다.
- 전 함체의 기본 전략 행동력은 2다. 전술 속도·사거리·재장전과 별개다.
- 전략 자원 부족으로 인한 전술 능력치 보정은 [[shortages]]의 TEST v1을 따른다.

## TEST 완성 함선 기준
- 기준 수치·모듈 합산과 비용은 [[shipdesigns]]에서 관리한다. 기준값을 선체에 더하지 않는다.
- `data/combat.json`의 benchmark는 검증 목표이고 실제 전투 능력치는 설계 조립 결과다.
- 전술 위치·사거리는 공통 단위다. 0.25초 고정 스텝, 이동은 속도 × 초당 단위(60) × 경과 초다.
- 무기별 발사 간격은 초 단위이며 각각 재장전한다. 전략 턴·행동력과 별개다.
- `abilities`: stealth, intercept, drawFire. `light`는 경량 판정이다.
- `line`에 따라 전열·중열·후열에 배치한다. 함선은 2차원 위치에서 이동하며 사거리와 감지는 실제 좌표 간 거리를 사용한다.

## 전술 AI와 표적 가중치

| 함급 | 기본 표적 우선순위 |
| --- | --- |
| 초계함 | 전함 → 중순양함 → 구축함 → 호위함 → 초계함 |
| 호위함 | 초계함 → 호위함 → 구축함 → 중순양함 → 전함 |
| 구축함 | 구축함 → 중순양함 → 초계함 → 호위함 → 전함 |
| 중순양함 | 중순양함 → 구축함 → 호위함 → 초계함 → 전함 |
| 전함 | 중순양함 → 전함 → 구축함 → 호위함 → 초계함 |

- 기본 순위 점수에 사거리 내 무장 비율, 거리, 자신을 겨눈 가까운 적, 함급별 위협을 반영한다. 동점은 함선 ID 순으로 결정한다.
- 표적을 최소 1.5초 유지하고, 이후 새 표적이 기존 표적보다 12점 넘게 앞서면 전환한다. 격파되거나 감지할 수 없는 표적은 즉시 다시 선택한다.
- 초계함은 전열 뒤의 표적이 사거리 밖에 있으면 좌우로 벌어져 전열을 지난 뒤 후방으로 접근한다.
- 호위함은 아군 전함을 우선 보호하고, 전함이 없으면 중순양함을 엄호한다. 접근하는 초계함을 감지하면 주력함과 초계함 사이로 이동해 사격한다. 실제로 교전 중인 호위함은 초계함의 표적 점수에 영향을 주며 피해는 개별 함선에 적용된다.
- 구축함은 아군을 위협하는 가까운 초계함에 대응할 수 있다. 중순양함은 먼저 교전하는 전열에서 주변 적의 표적 점수에 영향을 준다. 전함은 중순양함 뒤에서 긴 사거리를 활용한다.
- 가중치·유지 시간·전환 기준·배치 간격·감지·우회·엄호 위치는 `data/combat.json`의 `tactics`에서 조정한다. 기존 감지·차단·전열 유도 반경은 `rules`에 둔다.

## 실제 처리 규칙
- 명시적인 적대 관계가 있는 진영끼리만 표적 선정·사격한다. 중립·비참전 함선은 제외한다.
- 초계함은 최초 발사 전까지 은폐한다. 일반 함선은 감지 거리 밖의 은폐 함선을 표적으로 삼지 못한다.
- 호위함은 일반 함선보다 더 먼 거리에서 은폐한 초계함을 감지한다. 구축함이 경량 함선에 명중하면 기존 대경량 피해 배율을 적용한다.
- 최종 명중 확률은 `clamp(0.85 − 대상 회피, 0.15, 0.95)`다. 함체별 기존 accuracy 스냅샷이나 추가 명중 보정은 사용하지 않는다.
- 이전 TEST의 전함 근거리 추적 배율은 폐기했다. 현재 명중 공식에 중복 보정을 더하지 않는다.
- 보호막에 먼저 무기별 배율을 적용하고, 관통한 나머지를 원래 피해로 환산한 뒤 장갑 배율을 적용한다. 장갑 0이면 격파된다.
- 함급별 선호 사거리 또는 전술 위치로 이동한다. 이동 후 각 무기의 사거리와 재장전 상태를 확인해 사격한다.
- 양측 모두 은폐하여 표적이 없으면 상대 방향으로 접근한다. 감지 거리 이내가 되기 전에는 사격하지 않는다.
- 발사 간격의 소수 잔여 시간을 다음 스텝으로 이월한다. 1.2·1.6초 무기를 1.25·1.75초로 고정 반올림하지 않는다.
- 같은 스텝의 이동과 발사 자격은 일괄 확정하여 동시 격파가 가능하다. 피해는 함선·무장 순서로 처리한다. 재장전은 경과 초만큼 감소한다.
- 마지막 생존 진영이 승리하며 모두 격파되면 무승부다.

## 공통 상태와 검증
- CombatUnit: 기존 전투 상태에 y, direction, flankSide, targetId, targetSinceTick을 포함한다.
- CombatState: version(4), tick, seed, units, hostilities, events, winner.
- 사격 기록: type, attackerId, targetId, weaponIndex, damageType, hit, damage(원래 피해), shieldDamage, armorDamage.
- 상태는 JSON으로 직렬화 가능하며 난수 상태도 저장한다. 동일 초기 상태와 시드의 결과는 같다.
- 설계 저장은 [[shipdesigns]], 군함·전투 진행 저장은 [[fleets]]·[[saves]]를 따른다. 전투 창에서 후퇴 결정과 전투 저장을 제공한다. [[retreat]]
- `npm test`: 데이터 무결성, 은폐·차단·표적 유도, 회피·피해·재장전, 전투 종료·직렬화 재현 검증.
- `npm run check`: 전투 데이터 검증을 기존 문법·JSON·번들 검사에 포함한다.

## 공동 교전과 회복
- 선택한 공격 함대 전부와 목적지의 명시적 적대 군함 전부를 한 번의 전투로 처리한다. 방어 측 예비·수리 중 함선도 포함한다.
- 선택하지 않은 공격 측 함선, 중립 진영, 관계가 지정되지 않은 진영을 자동 참전시키지 않는다.
- 공격자는 일반 이동 비용만 지불한다. 방어자는 방어 자체로 행동력를 지불하지 않는다. 전투 결과가 양측 행동력를 0으로 만들지 않는다.
- 격파는 장갑 0일 때 발생하며 생존자의 손상·보호막·각 함대 구분을 보존한다. 결과 창에 생존/격파·장갑·보호막·행동력를 표시한다.
- 보호막 회복 TEST: 그 턴에 교전하지 않은 생존 군함은 턴 경계에 최대 보호막의 25%를 회복한다. 최대치 이상은 회복하지 않는다.
- lastCombatTurn·lastShieldRecoveryTurn을 저장하여 같은 턴 재호출·불러오기 중복 회복을 막는다. 교전한 턴 경계에는 회복하지 않는다.
- 보호막 회복은 행동력·장갑에 영향을 주지 않는다. 장갑은 [[shipyards]]에서만 수리한다.
- 관계 데이터는 [[fleets]], 시뮬레이션 결과와 한계는 [[combatbalance]]를 따른다.
- 전투 창의 이동·사격 표시와 개발용 고정 교전은 [[combatui]]를 따른다.
