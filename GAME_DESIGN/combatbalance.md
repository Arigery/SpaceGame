# 자동 전투 TEST 검증 기록

> 요약: 전술 배치·표적 점수를 적용한 역할별 교전 재시험
> 상태: 논의중
> 연관: [[combat]], [[fleets]], [[shipdesigns]]

## 기준과 재현
- 2026-11-18, `npm run balance`로 재현한다. 게임 저장이나 자원을 변경하지 않는다.
- 표준 1단계 장비, 양측 기준점 거리 900, 전열·중열·후열 배치, 각 사례 40개 시드, 명시적 적대 쌍을 사용한다.
- 시드는 `Math.imul(1~40, 2654435761) >>> 0`이다. 같은 데이터와 시드는 같은 결과를 낸다.
- 전투 공식·보호막 회복 수치의 관리 기준은 [[combat]]이다. 군함 완성 기준 수치는 [[shipdesigns]]다.
- 일부 사례는 정원/비용이 같지 않다. 사례명에 실제 구성을 명시하며 모든 조합이 공정한 결투라는 뜻은 아니다.

## 현재 결과
| 공격 측 | 방어 측 | 공격 승 / 방어 승 / 무승부 | 평균 전투 시간 |
| --- | --- | --- | ---: |
| 초계함 10 | 전함 1 | 40 / 0 / 0 | 36.46초 |
| 초계함 10 | 호위함 5 | 40 / 0 / 0 | 54.01초 |
| 초계함 10 | 구축함 3 | 0 / 40 / 0 | 41.88초 |
| 초계함 10 | 전함 1 + 호위함 2 | 2 / 38 / 0 | 56.54초 |
| 초계함 10 | 초계함 10 | 22 / 18 / 0 | 50.74초 |
| 혼성 50점 함대 | 같은 혼성 50점 함대 | 23 / 17 / 0 | 120.41초 |

- 240개 교전 모두 계산 제한 이내 종료했다. 50점 사례는 양측에 전함 1, 중순양함 3, 구축함 3, 호위함 4, 초계함 5를 배치했다.
- 초계함은 호위 없는 전함을 상대할 수 있고, 구축함은 경량 함대에 강하다.
- 호위함을 붙인 전함 편대는 차단 효과를 보였으며, 초계함 쪽의 승리도 발생했다. 이 비교는 방어 정원이 10점에서 14점으로 증가하는 구성이므로 호위함만의 효과량을 분리하지 않는다.
- 다른 혼성 구성과 연구 단계 차이는 추가 검증 대상이다.

## 이번 조정
- 초계함이 우회 도중 전열에 사격하러 되돌아오는 사례를 확인해 측면 이동 폭을 205로 조정했다.
- 우선순위는 유지하면서 직접 위협 가중치를 40, 구축함의 아군 측면 대응 가중치를 54로 조정했다.

## 이전 전투 계산 조정
- 이전 전함 근거리 추적 페널티 제거: 요청된 공통 명중 공식에 추가 배율을 섞지 않는다.
- 함급 기본 장갑·보호막·피해를 임의로 올리지 않았다. 별도 초계함 대전함 피해 보너스도 넣지 않았다.
- 고정 스텝에서 발사 간격의 잔여 시간을 보존하여 연사 무기가 불필요하게 느려지는 문제를 수정했다.
- 숨은 적을 감지하기 위한 접근과 사격 가능 표적을 구분하여 양측 은폐 시 교착을 제거했다.
- 보호막은 평온한 턴에 부분 회복하고 장갑은 자원·시간을 쓰는 수리에 남겨, 전투 손상이 전부 무료 복구되지 않도록 했다.

## 회귀 검사 범위
- 선택한 공격자 전원과 명시적 적대 방어자 전원의 단일 교전.
- 방어 행동력 보존·공격 이동 비용만 차감·중립 및 미선택 함선 불참.
- 보호막 우선 흡수·장갑 관통·격파·장비별 발사 주기·시드 재현.
- 적대 관계 저장·해제·기본 중립, 턴당 보호막 회복과 중복 회복 방지.
- 조선소 수리·생산·경제·연구 및 이전 단위 테스트를 함께 실행한다.
- 실제 화면·브라우저 조작은 검사하지 않았다.
