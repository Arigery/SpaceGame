# 4성계 전투 테스팅

> 요약: 4성계에서 양측 편성과 AI 태세를 설정하고 전투·점령·조선소를 시험
> 상태: 논의중
> 연관: [[combatui]], [[fleets]], [[shipdesigns]], [[shipyards]], [[retreat]]

## 시작과 지도

- 메인 메뉴의 **전투 테스팅**은 튜토리얼 바로 아래에 있다.
- 일렬 지도는 테라 조선소 → 테라 전선 → AI 전선 → AI 조선소다. 시작 시 좌측 두 성계는 플레이어, 우측 두 성계는 적 AI 소유다. 시험 중에도 [[fleets]]의 점령에 따라 성계와 연결선 표시가 바뀐다.
- 성계와 항로는 캠페인 은하 지도의 발광 심볼·이름표·이동 강조를 공유한다. 적 성계는 주황 계열로 구분한다.
- 성계 위에 함대는 삼각형, 같은 군단의 여러 함대가 함께 있으면 겹화살표 군단 아이콘으로 표시한다. 함대가 서로 다른 성계에 떨어져 있으면 각 성계의 실제 배치에 따라 표시한다.
- 시작 전에는 편성·설계·태세를 고른다. 양측 편성을 확인한 뒤 우측 상단 **플레이 시작**을 눌러야 함대가 배치되며, 각 진영의 함대는 자기 쪽 끝 성계에서 출발한다.
- 시험은 고정된 맵과 시드를 사용한다. **편성으로 돌아가기**를 이용하면 현재 시험 진행을 초기화하고 같은 편성 또는 다른 태세로 다시 시작할 수 있다.
- 시험은 캠페인 상태와 저장 슬롯에 영향을 주지 않는다. 시작 전 편성표의 함선은 시작 시 배치하며 건조 대기열이나 누적 비용에 넣지 않는다.

## 시험 성계와 조선소

- 네 성계는 각 진영이 개척한 상태로 시작한다. 각 성계에는 거주 가능 행성 하나, 행성 중심지, 개척 우주정거장, 완공된 궤도 조선소가 있다. 시험 성계는 일러스트 없이 캠페인과 같은 항성·행성 모델, 조선소 표시, 항로 삼각형, 휠 확대 및 드래그를 사용한다.
- 플레이어 개척선은 테라 조선소 성계에서 출발한다. 은하 지도나 현재 성계에서 개척선을 선택한 뒤 **이동**을 누르면 기존 항로 AP로 이동한다. 현지의 선택된 개척선으로 행성을 우클릭해 조선소를 열 수 있다.
- 조선소 착공·직접 생산·함대 수리·증원은 [[shipyards]]의 공통 주문과 진행 규칙을 사용한다. 적대 점령 및 조선소 인수는 [[fleets]]를 따른다. 시작 후 함대 상세에서 **함대 증원**, 해당 성계나 함대 상세에서 **조선소·수리**를 연다.
- 시험 모드의 자원은 무제한이다. 제작·수리·배송 시간과 편제 한도는 기존과 동일하다. 양측의 유지비와 플레이어가 주문한 작업의 자원 소모를 기록한다.

## 소유 함대 → 상세 보기

| 탭 | 편집·확인 항목 |
| --- | --- |
| 함대 리스트 | 왼쪽 군단·독립 함대 목록과 새 함대 창설. 오른쪽 선택 항목의 상세와 편집. 군단 추가와 양측 편성 확인 |
| 함선 설계 | 기존 설계 UI로 설계 복제·이름·슬롯 수정, 설계 저장 |
| 데이터 | 시험 전용. 선택 진영의 편성·생존 척수, 설계별·시작 편성별 예상 비용과 건조 턴, 실제 누적 비용과 현재 턴당 비용 |

- 진영별 설계 목록은 독립적이다. 시험에서는 모든 함체와 모듈을 사용할 수 있으며, 전력·슬롯 검사와 편제 규모는 [[shipdesigns]]와 [[fleets]]의 공통 규칙을 사용한다.
- 군단은 시험 편성에서 함대를 묶는 단위다. 이동·전술·행동력은 기존 함대 규칙을 사용한다.
- 왼쪽에서 군단을 클릭하면 그 아래에서 소속 함대 목록을 펼치거나 접는다. 소속 함대나 독립 함대를 선택하면 오른쪽에서 편제를 확인한다.
- **새 함대 창설**은 독립 함대를 만든다. 시작 전 군단 상세의 **소속 함대 추가**와 함대 상세의 소속 변경으로 시험 편성을 구성한다.
- 시작 전 함급 카드는 설계별 척수 조절(`+`/`−`)과 초기 보호막·장갑을 함께 표시한다. 시작 후에는 같은 카드에서 개별 함선의 현재/최대 보호막·장갑을 확인한다. 데이터 탭까지 같은 창 크기를 사용한다.
- 시작 전 편성 확인에는 양측 모두 하나 이상의 함대가 필요하다. 남겨 둔 빈 함대는 채우거나 삭제한다. 시작 후 플레이어 함대 관리는 캠페인과 같은 화면에서 새 함대 창설, 이름 변경, 편성 추가·해제, 빈 함대 해산, 이동·공격, 수리·증원을 이용할 수 있다. 시작 후 설계 수정은 해당 시험의 생산 설계에 적용한다.
- 데이터 탭의 예상 건조비·소요 턴 표는 시작 전 편성을 기준으로 한다. 시작 후 **실제 자원 소모**에는 조선소 건설, 생산·증원, 함대 수리 예약 비용, 함선·조선소 유지비가 별도로 나온다. 자발적 건조 취소의 환불은 생산 누적 비용에 반영한다.

## 시험 진행

- 지도에서 군단·함대 표식을 클릭하거나 우측 소유 함대 목록에서 함대를 고르면 함선 패널에 선택과 공동 이동 한도를 표시한다. Shift/Ctrl/Command로 선택을 추가·해제한다. **이동**을 눌러야 도달 가능한 성계를 강조하며, 강조된 성계를 클릭해 이동·공격한다. Esc는 명령 모드만 취소한다.
- 이동 명령이 꺼져 있으면 소유하거나 점령을 마친 성계를 클릭해 진입한다. 진입하는 성계에 있는 함대나 개척선은 선택을 유지한다. 은하 지도 여백을 클릭하거나 턴을 완료하면 함대 선택을 해제한다. 성계 안의 편대 이동은 [[systemview]]를 따른다.
- 성계 화면의 군단 배지를 누르면 현지 소속 함대를 함께 선택한다. 빈 공간을 우클릭하면 본게임과 같은 대형·곡선 선회 연출로 이동한다.
- 다음 턴에 AI가 움직인다. 수비형은 자기 전선에 도착하면 대기한다. 공격형은 플레이어 전선까지 진격하고, 그곳에 교전할 함대가 없으면 이후 턴에 플레이어 후방 함대를 추적한다.
- 양측 함대가 만나면 기존 자동 전투 화면을 연다. 전체·함대별 후퇴, 일시정지, 단거리 후퇴·긴급 워프, 결과와 지도 복귀를 같은 흐름으로 시험한다.
- 턴당 유지비를 집계하고 생산·수리를 진행한 뒤 AI 명령을 처리한다. 교전 도중에는 다음 턴 확정과 증원 합류를 보류한다. 모든 교전이 끝나면 워프 복귀와 증원 도착을 처리한다.
- 코드 검증 범위는 편성·태세·후퇴, 소유 성계 입장과 점령, 생산과 수리 병행, 증원 도착 턴, 자원 집계와 캠페인 상태 보존이다.
