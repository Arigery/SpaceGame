# 4성계 전투 테스팅

> 요약: 메인 메뉴에서 양측 편성과 AI 태세를 설정하고 전투·후퇴를 시험
> 상태: 논의중
> 연관: [[combatui]], [[fleets]], [[shipdesigns]], [[shipyards]], [[retreat]]

## 시작과 지도

- 메인 메뉴의 **전투 테스팅**은 튜토리얼 바로 아래에 있다.
- 일렬 지도는 테라 조선소 → 테라 전선 → AI 전선 → AI 조선소다. 좌측 두 성계는 플레이어, 우측 두 성계는 적 AI 소유다.
- 성계와 항로는 캠페인 은하 지도의 발광 심볼·이름표·이동 강조를 공유한다. 적 성계는 주황 계열로 구분한다.
- 성계 위에 함대는 삼각형, 같은 군단의 여러 함대가 함께 있으면 겹화살표 군단 아이콘으로 표시한다. 함대가 서로 다른 성계에 떨어져 있으면 각 성계의 실제 배치에 따라 표시한다.
- 시작 전에는 편성·설계·태세를 고른다. 양측 편성을 확인한 뒤 우측 상단 **플레이 시작**을 눌러야 함대가 배치되며, 각 진영의 함대는 자기 쪽 끝 성계에서 출발한다.
- 시험은 고정된 맵과 시드를 사용한다. **편성으로 돌아가기**를 이용하면 현재 시험 진행을 초기화하고 같은 편성 또는 다른 태세로 다시 시작할 수 있다.
- 캠페인 상태와 저장 슬롯은 별도로 관리한다. 비용 화면은 기존 설계를 기준으로 산출하며 시험 편성에는 실제 생산 예약·자원 차감을 적용하지 않는다.

## 소유 함대 → 상세 보기

| 탭 | 편집·확인 항목 |
| --- | --- |
| 함대 리스트 | 왼쪽 군단·독립 함대 목록과 새 함대 창설. 오른쪽 선택 항목의 상세와 편집. 군단 추가와 양측 편성 확인 |
| 함선 설계 | 기존 설계 UI로 설계 복제·이름·슬롯 수정, 설계 저장 |
| 데이터 | 시험 전용. 선택 진영의 편성·생존 척수와 턴당 유지비, 시작 전 설계별·함대별 건조비와 단일 조선소 순차 건조 턴 수 |

- 진영별 설계 목록은 독립적이다. 시험에서는 모든 함체와 모듈을 사용할 수 있으며, 전력·슬롯 검사와 편제 규모는 [[shipdesigns]]와 [[fleets]]의 공통 규칙을 사용한다.
- 군단은 시험 편성에서 함대를 묶는 단위다. 이동·전술·행동력은 기존 함대 규칙을 사용한다.
- 왼쪽에서 군단을 클릭하면 그 아래에서 소속 함대 목록을 펼치거나 접는다. 소속 함대나 독립 함대를 선택하면 오른쪽에서 편제를 확인한다.
- **새 함대 창설**은 독립 함대를 만들고, 군단 상세의 **소속 함대 추가**는 해당 군단에 함대를 만든다. 함대 상세에서 군단 또는 독립으로 소속을 바꿀 수 있다.
- 시작 전 함급 카드는 설계별 척수 조절(`+`/`−`)과 초기 보호막·장갑을 함께 표시한다. 시작 후에는 같은 카드에서 개별 함선의 현재/최대 보호막·장갑을 확인한다. 데이터 탭까지 같은 창 크기를 사용한다.
- 편성 확인에는 양측 모두 하나 이상의 함대가 필요하다. 남겨 둔 빈 함대는 채우거나 삭제한다. 시작 후 편성은 열람할 수 있다.
- 데이터 탭의 건조비와 소요 턴은 시작 전 편성을 기준으로 한다. 현재 유지비는 시작 후 생존 함선 수에 따라 바뀐다.

## 시험 진행

- 지도에서 군단·함대 표식을 클릭하거나 우측 소유 함대 목록에서 함대를 고르면 이동 대상을 선택한다. Shift를 누른 채 클릭하면 선택을 추가하거나 해제한다. 강조된 성계를 누르면 기존 공동 이동·공격 명령을 실행한다.
- 다음 턴에 AI가 움직인다. 수비형은 자기 전선에 도착하면 대기한다. 공격형은 플레이어 전선까지 진격하고, 그곳에 교전할 함대가 없으면 이후 턴에 플레이어 후방 함대를 추적한다.
- 양측 함대가 만나면 기존 자동 전투 화면을 연다. 전체·함대별 후퇴, 일시정지, 단거리 후퇴·긴급 워프, 결과와 지도 복귀를 같은 흐름으로 시험한다.
- AI 단계의 교전은 플레이어 선택과 교전이 끝날 때까지 해당 턴을 보류한다. 워프 복귀는 시험 턴 경계에 처리한다.
- 코드 검증 범위는 양측 편성 확인, 끝 성계 배치, 설계 격리와 편제 한도, 태세별 이동, 개별 워프, 군단 펼침, 척수 편집, 손상 반영과 캠페인 상태 보존이다.
