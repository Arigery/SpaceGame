## 6. 공사와 턴 진행

### 6.1 확정된 구조

- 거주 가능 행성의 공사는 해당 행성 생산력을 매 턴 누적한다.
- 광물·가스 행성 공사는 생산력을 사용하지 않는 독립 타이머다.
- 채굴 시설 목표 Lv.1/2/3의 고정 공사 시간은 각각 5/8/12턴이다.
- 개척된 성계라면 거주 가능 행성이 없어도 채굴 시설을 건설할 수 있다.
- 건물 효과·중심지 기본 생산·작업자 규칙은 5절을 따른다.

### 6.2 현재 적용 중인 2차 테스트 운영 규칙

- 다음은 구현된 테스트 기준이며 세부 운영 규칙의 최종 확정과 구분한다.

| 항목 | 적용 방식 |
| --- | --- |
| 동시 공사 | 거주 행성당 1개. 여러 행성 및 채굴 타이머는 독립 진행 |
| 착공 비용 | 전액 선지불. 부족하면 착공하지 않고 아무 자원도 차감하지 않음 |
| 예상 기간 | 남은 필요 생산력 ÷ 현재 생산력을 올림 |
| 작업자 재배치 | 공사 중 가능. 다음 턴 생산력·예상 기간에 반영 |
| 업그레이드 중 | 기존 단계 효과·유지비 유지 |
| 신규 미완공 건물 | 생산·효과·유지비 없음 |
| 완공 반영 | 완공 후 이어지는 턴 정산부터 새 효과·생산·유지비 적용 |
| 초과 생산력 | 이월하지 않음 |
| 공사 중 행성 조작 | 추가 공사·철거·부속 해제를 잠금 |
| 취소·환불·대기열 | 미결정, 새 기능 미구현 |

- 현재 한 턴의 처리 순서:

1. 현재 건물 기준 생산·인구 소비·유지비를 계산한다.
2. 성장 전 인구·배치 기준 생산력으로 공사를 진행하고 기존 건물 기준으로 인구를 성장시킨다.
3. 자원을 정산한다. 결과는 0 아래로 내려가지 않는다.
4. 기간제 탐험 효과의 남은 턴을 갱신하고, 정산된 연구력 재고를 현재 연구에 투입한다(최대 1개 완료).
5. 완공한 건물·시설·확장을 반영하고 [[shipyards]]의 생산·수리를 진행한다.
6. [[fleets]]의 AI 명령 처리와 군함 AP 복구 후 턴 증가·민간 AP 복구를 진행하고 연구·공사 완료를 기록한다.

- 일반 게임에서 연구가 없고 선택 가능한 기술이 있으면 1단계 이전에 연구 화면을 연다. 연구 시작을 누르면 이 턴을 계속 처리하고, 닫으면 정산 없이 취소한다.

- 이 순서로 완공한 시설이 완공 직전 턴의 정산에 소급 적용되지 않게 한다. 최종 턴 순서, 이월, 환불 등은 [[questions]]에서 후속 결정한다.

## 7. 비용·작업량·유지비 — 현재 적용 2차 테스트 수치

- 이 절은 **최종 밸런스 확정표가 아니다.** 채굴 시설의 5/8/12턴은 확정 규칙이며, 나머지 조정 가능한 수치는 2차 테스트 기준이다.
- 신규 개척 행성의 첫 건설 지원 보너스는 적용하지 않는다. 모행성 인구 6명, 신규 개척 거주 가능 행성 인구 3명을 유지한다. 변경된 생산력은 새 착공에 적용하며, 진행 중·저장된 공사는 착공 당시 필요량과 진행도를 유지한다. 취소·건설 대상 변경 기능은 추가하지 않는다.

- 거주 행성의 '비교 턴'은 생산력을 계속 6/턴으로 고정한 경우다. 실제 인구 성장과 작업자 재배치에 따라 기간이 바뀐다.
- 업그레이드 비용은 해당 단계에 추가로 지불하는 금액이며 유지비는 완공 후 총액이다.
