# 결정 이유

> 요약: 원문에서 추출한 이유와 이전 문서 운영 근거
> 상태: 확정
> 연관: [[workflow]], [[pillars]]

- 2026-11-18 결정. 기본 함급 우선순위를 상황별 점수와 결합하고, 표적 전환 기준을 두어 함선이 교전과 임무를 이어가게 한다. [[combat]]

- 2026-11-18: 요청된 공통 명중 공식을 유지하기 위해 이전 전함 추적 페널티를 제거했다. 은폐 양측의 교착과 소수 발사 간격 반올림을 수정하고, 회복은 평온한 턴에 한 번만 적용한다. [[combat]], [[combatbalance]]

- 2026-11-18: 조선소는 예약 시 비용과 조립 상태를 고정하여 재로드·설계 편집의 중복 차감을 막는다. 초기 초계함은 연구 없이 생산 가능하게 하고 후속 함체·무기 연구를 분리했다. [[shipyards]]

- 2026-11-18: 완성 함선 기준값 중복 가산 방지를 위해 benchmark와 조립 수치를 분리했다. 초계함의 전함 우회 역할이 초기 시뮬레이션에서 약해 기준 능력치는 유지하고 전함 근거리 추적만 TEST 보정했다. [[shipdesigns]], [[combat]]

- 채굴 Lv.2와 광산 Lv.3는 한정된 부지에서 순수입을 앞당기는 선택을 만들므로 시험 비용을 유지한다. 가스 Lv.3는 대규모 에너지 수요를 검증한 뒤 재검토한다. [[mining]], [[validation]]
- 연구 특화의 소비재 가동비는 현행 시험값을 유지한다. 연구 작업자 4명 조건에서는 중심지 생산으로 감당할 수 있어, 여러 행성에 연구 시설을 늘린 조건에서 다시 비교한다. [[economy]], [[validation]]
- 소비재·신소재 원재료 단가는 120턴 시험에서 중반 건설 지연이 적었던 0.5를 채택한다. 기초 채굴 생산을 유지하며 후반 특화 성장으로 공급 비중을 조정한다. [[economy]], [[mining]], [[validation]]

- 새로 추론한 이유는 추가하지 않는다. 혼합 문장은 조건·수치 손실을 막기 위해 전체를 보존한다.
- 기존 결정 이력: [DECISIONS.md](../DECISIONS.md). 이 파일에 그 전문을 복제하지 않는다.
- 아래 원문 단일 문서 운영 설명은 이관 전 이력이다. 현재 주제별 기준은 [[workflow]]를 따른다.

- 이 문서는 현재 게임 기획의 단일 기준이다. 합의된 변경은 해당 시스템 본문에 직접 반영한다. 대체된 초안이나 이전 문서 전문을 뒤에 덧붙이지 않는다. 변경 이유는 DECISIONS.md, 이전 수치와 문서 원문은 Git 이력에서 확인한다. (원문 L5)
- 목표 플레이 시간은 3~5시간이다. 초반 성장과 확장을 빠르게 하기 위해 [[buildings]]·[[specialization]]·[[mining]]의 기본 건물 및 공용 구역 첫 확장 필요 생산력을 낮춘다. 비용·유지비·생산량·후속 강화 수치는 유지한다. (원문 L33)
- 이후 주요 시스템의 변경이 이어질 것으로 판단해 현재는 제작 당시의 튜토리얼 코드를 보존하고 사용자 진입은 비활성화한다. 주요 시스템이 충분히 확정되면 최신 규칙·화면·조작에 맞춰 다시 설계한다(2026-11-12 사용자 확인). (원문 L60)
- 다른 승리가 달성되지 않아도 게임을 종료하는 안전장치다. 세부 점수 가중치는 미결정이다. (원문 L674)
- **목적**: 목적 있는 탐험과 우연한 발견을 함께 제공한다. 현재 이벤트 발생 빈도를 고려해 기존 33% 제안을 **25%**로 대체한다. 이는 전체 성계의 이벤트 발생률이 아니라 실제 이벤트가 있는 성계의 사전 단서 노출 확률이다. (원문 L726)
