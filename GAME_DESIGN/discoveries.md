### 11.3 연쇄 탐사 — 후속 기획 / 미구현

- 하나의 발견이 다른 성계의 단서를 제공하여 여러 성계를 연속 탐험하게 하는 선택적 확장 콘텐츠다. 단순 자원 지급보다 다음 탐험 목표를 제공하는 것이 핵심이다.

| 단계 | 진행 기획 |
| --- | --- |
| 1. 신호 발견 | 미확인 신호 또는 이상현상을 발견하고 발생 방향·대략적인 위치 단서 획득 |
| 2. 단서 확보 | 관련 성계로 이동해 추가 탐사, 정체 일부와 다음 목적지 확인 |
| 3. 최종 발견 | 발원지에 도착해 특별한 우주 현상 또는 탐험 결과 발견 |

- 가능한 결말은 고대 흔적 위치, 우주의 경이, 희귀 행성 특성, 특별한 자원 매장지, 연구력·일회성 보상, 위험한 우주 현상, 추가 미탐험 지역 정보다. 긍정·부정 결과 모두 가능하며 반드시 우주의 경이로 끝나지 않는다.
- 일반 이상현상의 짧은 팝업·결과, 거주 행성의 선택형 스토리·확률 판정, 자원 보상·영구 특성은 유지한다.
- 일부 이벤트에만 추가 연결하며 모든 이벤트를 연쇄 탐사로 바꾸지 않는다. 기존의 불모 일반 이상현상 부정형 제외 규칙도 그대로 두고 연쇄 콘텐츠의 위험 결과와 구별한다.
- 발생 빈도·연결 성계 수·보상·실패 조건은 미확정이다. 현재 불모 이벤트의 단서 보상만으로 연쇄 탐사가 구현됐다고 간주하지 않는다.

### 11.4 고대 흔적과 우주의 경이의 역할

| 콘텐츠 | 목표 역할 — 후속 기획 |
| --- | --- |
| 고대 흔적 | 유물 조각·과학 승리, 여러 성계 탐험의 장기 목표, 문명별 독립 조사, 일부 신호·연쇄 탐사 연결 |
| 우주의 경이 | 은하 규모의 희귀 천체·현상, 일반 행성 특성과 다른 특별한 효과, 인접 성계·이동·탐험·지역 전략에 영향 |

- 두 콘텐츠는 연결될 수 있지만 같은 시스템이 아니다. 우주의 경이 종류·배치 수량·효과는 추후 결정한다. 현재 고대 흔적은 발견 표시·팝업 단계이며 유물 조각과 최초 연구 보상은 아직 지급하지 않는다.
