### 11.3 연쇄 탐사 — 초기 테스트

- 새 은하에 각 1개를 배정한다. 기존 저장에 새 경로를 삽입하지 않는다. 비거주 행성 최초 탐사 문명만 진행권을 얻는다. 개척·점령은 진행권을 이전하지 않는다.
- 첫 발견은 일반 탐사의 행동력 1에 포함한다. 중간·최종 목표는 탐사선이 각 성계에 방문해 행동력 1씩으로 조사한다. 단계 사이는 2~4 항로이며 주요 이상현상 대상 행성과 중복하지 않는다.
- 시간 제한 없이 같은 문명의 모든 탐사선이 이어서 진행할 수 있다. 자기 진행의 현재 목표에만 청록색 표식을 표시한다. 목적지 표식은 주변 성계·항로와 진입 권한을 공개하지 않는다.
- 고정 결과는 알림, 관제소·최종 보상·정보 대상 선택은 팝업으로 표시한다. 진행권·선택·보상 완료 상태를 저장한다.

| 연쇄 | 최종 보상 |
| --- | --- |
| 사라진 탐사 함대 | 연구력 +80 또는 신소재 +50 |
| 심층 결정의 기원 | 지정 광산의 광물 생산 영구 +15% |
| 사라진 에너지의 흔적 | 에너지 +80 또는 지정 채집소의 에너지 생산 영구 +15% |
| 잊힌 생태계 복원 계획 | 지정 거주 가능 행성의 식량 생산 영구 +15% |
| 은하 관측 기록 | 중간 관제소 두 곳 중 한 곳 선택. 최종 연구력 +50과 거리 3 이내 지도 공개·미방문 성계 최대 3곳의 구성 정보 선택 |

- 영구 생산 효과는 해당 행성에 귀속된다. 수치와 단계명은 `data/exploration.json`의 `chains`에서 관리한다.

### 11.4 고대 흔적과 우주의 경이의 역할

| 콘텐츠 | 목표 역할 — 후속 기획 |
| --- | --- |
| 고대 흔적 | 유물 조각·과학 승리, 여러 성계 탐험의 장기 목표, 문명별 독립 조사, 일부 신호·연쇄 탐사 연결 |
| 우주의 경이 | 은하 규모의 희귀 천체·현상, 일반 행성 특성과 다른 특별한 효과, 인접 성계·이동·탐험·지역 전략에 영향 |

- 지역형 경이의 배치는 [[wonders]], 유적 조사와 최초 획득 효과는 [[relics]]를 따른다.
- 적대 세력 이상현상의 강제 후퇴와 복귀 규칙은 [[anomalies]]를 따른다.
