# 자원 경제

> 요약: 자원 생산·소비·유지비 및 보정 원칙
> 상태: 논의중
> 연관: [[population]], [[specialization]], [[questions]]

- 군함과 완공된 소유 조선소 유지비를 별도 항목으로 합산한다. 함대 수리의 신소재·에너지는 예약 비용이며 청구 규칙은 [[shipyards]]를 따른다.


- 자원 생산: 기존 중심지 및 특화 건물의 작업자·물류·부속 건물 보너스를 계산한 생산량에 `max(0, 1 + 해당 자원 영구 보정 합)`을 곱한다. 소비량·유지비에는 적용하지 않는다.
## 4. 자원·인구·생산력

### 4.1 자원과 경제 원칙 — 확정

- 자원은 에너지·광물·식량·소비재·신소재·연구력 6종이다.
- 건설은 자원 비용과 작업량을 함께 사용한다. 건물 비용은 주로 광물, 함선 비용은 주로 신소재를 사용하는 방향이다.
- 건물 유지비는 광물+에너지, 함선 유지비는 신소재+에너지를 기본 원칙으로 한다.
- 아직 비어 있는 상세 금액은 [[questions]]에 명시한다. 일부 미정 자원이 있다고 전체 비용을 임의로 보완하지 않는다.

- 생산·성장·건설 보정은 기존 영구 행성 보정 합에 더한다. 특화의 기본 작업자·부속·물류 계산 순서, 기본 건설 비용, 유지비와 소비는 그대로다. 기존 설치 부속과 그 생산 효과, 착공된 공사는 유지한다.
### 6.3 유지비 적용

- 기본 유지비는 가동 중인 건물 1개당 부과한다.
- 연구력 특화 건물은 기본 유지비에 배치 인구 1명당 소비재 1/턴을 추가한다. 30턴 시험 후 유지한 수치이며 `data/buildings.json`의 `upkeepPerWorker`에서 조정한다. 행성 중심지의 기본 연구력에는 이 비용이 없으며, 거주 행성 수 보정과 소비재 행정 절감은 [[population]]의 인구 소비에만 적용한다. 시험 결과는 [[validation]]을 따른다.
- 중심지와 완공된 채굴 시설은 자동 가동하며 시작 시설도 유지비 대상이다.
- 작업자가 필요한 공용·특화 건물은 배치 시 유지비가 발생하고 미배치 시 청구하지 않는다.
- 인구의 식량·소비재 소비는 건물 유지비와 별개다.
- 미정 금액은 JSON에서 `null`로 관리하고 화면에 '미정'으로 표시한다. 알려진 금액만 합산한다.
- `null`은 무료 또는 0으로 확정했다는 뜻이 아니다. 상위 단계 미정 금액을 하위 단계 값으로 대체하지 않는다.
- 자원 부족 시 추가 정지·부채·패널티는 미결정이다. 현재는 기존 0 하한만 적용한다.

### 생산 원재료

- 소비재·신소재 특화 시설은 실제 생산량 1당 광물 0.5를 같은 턴에 소모한다. 작업자·물류·부속·연구·행성 특성을 반영한 최종 특화 생산이 기준이며, 행성 중심지의 기본 생산은 별도다.
- 광물 투입은 인구 소비·시설 유지비와 별도 항목으로 집계한다. 단가는 `data/buildings.json`의 `inputsPerOutput`에서 조정한다. 120턴 비교와 선택 근거는 [[validation]]·[[decisions]]를 따른다.
