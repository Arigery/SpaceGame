# 함대 편성과 공동 명령

> 요약: 확정 편제 규모 한도 50·함선 소유권·최저 AP 공동 이동·일괄 전투 진입
> 상태: 확정
> 연관: [[combat]], [[shipdesigns]], [[movement]], [[saves]], [[research]]

## 편제 규모와 목표 구성
- 함대당 편제 규모 한도는 **50**이다. 함급별 별도 척수 제한은 없다.
- 같은 성계에 여러 함대가 존재할 수 있다. 캠페인에는 군단·상위 편제를 두지 않으며, 시험 모드의 군단은 [[combattest]]를 따른다.
- 고도로 발전한 문명의 후반 목표는 약 8~9개 함대이며 전체 함대 수 제한이 아니다.

| 함급 | ID | 척당 편제 규모 |
| --- | --- | ---: |
| 초계함 | corvette | 1 |
| 호위함 | escort | 2 |
| 구축함 | destroyer | 3 |
| 중순양함 | heavy_cruiser | 6 |
| 전함 | battleship | 10 |

- 기함 함대 예시는 전함 1 + 중순양함 3 + 구축함 3 + 호위함 4 + 초계함 5로, 16척에 편제 규모 50이다.
- 위 구성은 목표 예시이며 강제 편제·자동 생성 템플릿이 아니다.
- 수치는 `data/combat.json`의 fleets에 저장하고 검증 도구에서 확정 값을 확인한다.

## 편성
- 빈 함대 창설·이름 변경·소유 예비 함선 추가·편성 해제·빈 함대 해산 제공.
- 추가는 같은 성계의 같은 소유자 함선만 가능하다. 한 함선은 한 함대에만 속한다.
- 편제 규모 한도를 초과하거나 중복·타 진영 소유·다른 성계 함선이면 추가를 거부한다.
- 편성 해제는 함선을 삭제하지 않으며 위치·손상·AP를 유지한다.
- 함선이 남아 있는 함대는 해산할 수 없다. 전멸한 함대는 빈 함대로 남긴다.

## 행동력과 공동 이동
- 군함 기본 AP는 매 턴 2이며 함급 공통이다. 연구 보정으로 증가할 수 있다.
- 함대 AP = 소속 함선의 **현재 AP 최솟값**.
- 다중 선택의 공동 이동 한도 = 선택된 함대 AP의 최솟값.
- 이동 버튼을 누르면 이 공통 한도에서 모든 선택 함대가 도달할 수 있는 목적지만 강조한다.
- 출발 성계가 달라도 같은 목적지로 공동 명령 가능. 각 경로의 비용이 공통 한도 이하여야 한다.
- 일반 항로 1, 양쪽 모두 해당 진영의 개척 성계인 항로 0.3. 최소 비용 경로를 사용한다.
- 예: AP 3과 1.3인 함대를 선택하면 이동 범위는 1.3 기준이다. 각 함선은 자신의 경로 비용만큼 차감한다.
- 목적지에 이미 있는 선택 함대의 이동 비용은 0이다. 빈 함대는 이동 명령에 포함할 수 없다.
- 더 빠른 함대의 남은 AP를 낮은 값으로 강제 통일하지 않는다. 손상·소유자·함대 ID도 보존한다.

## 일괄 적용과 교전
- 모든 선택 함대의 소유·단계·경로·AP를 검증한 뒤 복사한 상태에서 위치와 비용을 한꺼번에 적용한다.
- 하나라도 유효하지 않거나 전투 계산이 실패하면 전체 명령을 적용하지 않는다.
- 도착 성계에 적 군함이 있으면 선택된 모든 도착 함대와 명시적으로 적대하는 방어 군함을 하나의 전투로 처리한다. 함대별 순차 진입 전투는 없다.
- 생존 함선의 장갑·보호막을 각 함선에 돌려주고 격파 함선만 제거한다. 장갑 자동 수리는 없으며 전투 밖 보호막 회복은 [[combat]]를 따른다.
- 교전 창에서 진행에 따라 전체·개별 후퇴를 결정하고 종료 시 결과를 정산한다. AI 턴 재개와 긴급 워프 복귀는 [[retreat]]를 따른다.

## 현재 적용 안전 규칙 / 후속 기획과 구분
- 군함은 민간 `state.ships`와 별도 관리하여 탐사·개척 판정에 끼어들지 않는다.
- 현재 군함 이동은 이름/방문 정보가 공개된 성계만 허용한다. 미확인 성계 탐험 권한은 추가하지 않는다.
- 적 주둔 성계를 목적지로 공격할 수 있지만 다른 목적지로 가는 중간 경유지는 될 수 없다.
- `military.hostilities`의 명시적 진영 쌍만 상호 적대한다. 다른 소유자라는 이유만으로 공격하지 않는다. 기존 저장에 관계가 없으면 중립이다.
- 함대 메뉴의 교전 관계에서 확인된 진영과 적대를 설정·해제한다. 이는 전투 참가 판정용이며 외교 AI·조약 시스템은 아니다.
- 방어 대상은 공격 진영에 적대하는 목적지 군함이다. 중립 진영과 선택되지 않은 공격 측 함선은 참가하지 않는다.
- 전략 블랙홀 이동·성계 내부 군함 모델 조작은 아직 연결하지 않았다. 현재 공동 명령은 일반 항로 그래프를 사용한다.

## 턴·연구·AI 처리
- 현재 진영 단계에서만 편성·이동 명령 가능. 기존 이동 연출 중 다음 턴과 함대 명령은 UI에서 차단한다.
- 기존 경제·성장·건설·연구 정산 → AI 군함 AP 복구와 AI 명령 처리 → 플레이어 군함 AP 복구 → 턴 증가·민간 AP 복구.
- AI 자동 전략·문명 생성은 아직 없다. `settleFleetTurn(game, aiOrders)`로 전달된 명령을 처리할 수 있는 연결 지점과 순서를 검증했다.
- 연구 효과 `strategicAP`의 target은 military/all/함급 ID다. 현재 기술에 임의로 AP 연구를 추가하지 않는다.
- 연구 보정은 다음 군함 AP 복구 시 적용한다. 턴 도중 재편성으로 AP를 재지급하지 않는다.

## 화면·시험 도구·저장
- 전투 함선 메뉴에서 편성을 관리하고 선택한 함대의 이동·공격을 명령한다. 상세 배치는 [[combatui]]를 따른다.
- 은하 지도 함대 삼각형 선택, Ctrl/Shift/Command로 선택 추가·해제, 이동 버튼으로 범위 표시.
- 지도 여백·민간 함선 선택·다음 턴·불러오기에서 선택 정리. Esc는 이동 모드만 취소한다.
- 현재 생산 진입점은 [[shipyards]]다. 기존 무료 TEST 생성 도구는 기본 비활성화하며 정상 플레이에 표시하지 않는다.
- 개발 검사용 시험 도구 활성화는 `fleets.testDeploymentEnabled`로 관리한다. 새 게임에서 군함을 자동 지급하지 않는다.
- `military.version: 1`에 ships/fleets/nextId/orderSerial/phase/lastOrder 보존. 군함별 조립 스냅샷·AP·손상·위치·소유자 저장.
- 이전 저장에는 빈 군함·함대 상태를 추가한다. 잘못된 소유·중복 편성·정원·손상 값은 불러오기 오류로 알리고 현재 게임을 대체하지 않는다.
- 검증: 정원 경계·50척 동일 함급·소유권·공동 범위·경로·시야·원자성·공동 전투·연구 AP·AI 단계·저장·기존 턴·UI 핸들러.
