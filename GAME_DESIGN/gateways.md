# 관문

> 요약: 번영 승리의 핵심 시설과 민간선·군함의 성계 간 직행
> 상태: 확정
> 연관: [[victory]], [[movement]], [[research]], [[saves]]

## 후보지와 착공

- 기본 은하 생성 후 모성계를 제외한 8개 성계를 후보지로 지정한다. 모성계와 선정된 후보지 사이의 거리로 분산하고, 연결 항로 3개 이상 또는 블랙홀 인접 성계에 가중치를 준다.
- 후보지에 거주 가능 행성을 최소 1개 확보한다. 새 지도의 후보지에 거주 가능 행성이 없으면 빈 슬롯을 채우거나 최대 5개일 때 마지막 비거주 행성을 교체한다.
- 이전 저장은 거주 가능 행성이 이미 있는 성계 중에서 고른다. 기존 행성과 건설 작업은 보존하며, 이전 관문 공학 완료 기록을 현행 기술로 이관한다. 튜토리얼과 전투 시험 지도에는 후보지를 생성하지 않는다.
- 소유한 후보지에서 개척·건설 IV단계 관문 공학 완료 및 현지 개척선이 필요하다. 같은 개척선이 동시에 여러 관문을 건설할 수 없으며 개척선은 완료까지 이동·개척·다른 공사를 할 수 없다. 완공 후 같은 위치에서 다시 사용한다.
- 이전 거점의 개발 조건을 유지한다. 해당 성계 내 같은 거주 가능 행성에 인구 6명 이상과 공용 구역 Lv.3 이상이 필요하다. 이 개발 조건은 착공·재개 시 확인한다.

| 항목 | 시험 수치 |
| --- | --- |
| 관문 공학 | 연구력 550, 선행 공용 구역 고도화 |
| 착공 | 신소재 90, 광물 30 |
| 건설 | 8턴 |
| 완공 유지비 | 에너지 5/턴 |
| 1회 이동 | 행동력 1 |

- 비용·기간·유지비는 `data/balance.json`에서 조정한다. 연구 비용은 `data/research.json`에서 관리한다.

## 직행과 점령

- 민간선과 군함을 선택한 뒤 관문 이동 명령에서 목적지를 고른다. 같은 문명의 완공 관문을 출발지와 목적지로 사용하며 일반 항로로 연결할 필요가 없다. 공동 명령은 선택된 모든 함대가 가동 관문에서 출발할 수 있어야 하고 각 함대가 행동력 1을 낸다.
- 함대의 명령 이동과 조선소의 자동 증원 배송을 구분한다. 자동 증원의 도착 턴 산식은 [[shipyards]]의 기존 초공간 항로 거리 기준을 따른다.
- 성계가 점령되면 관문은 시설 상태를 보존하며 새 소유자의 네트워크로 이전된다. 미완공 관문은 기존 개척선이 공사에서 풀리며, 새 소유자가 관문 공학과 현지 개척선 조건을 갖추면 남은 기간부터 재개한다.
- 턴당 유지비는 완공된 소유 관문부터 정산한다. [[victory]] 진행도는 현재 소유권 기준으로 갱신한다.

## 밸런스 검토

- 관문 4곳을 직접 지으면 신소재 360·광물 120, 개척선 작업 32턴 및 에너지 20/턴이 든다. 기준 전함 3척의 건조 신소재와 같은 규모다.
- 한 개척선으로 4곳을 직접 짓고 마지막 완공 정산을 유지 1턴으로 세면 첫 착공부터 최소 39회 정산이 필요하다. 연구·정착 개발·이동에 걸리는 시간은 별도다.
- 고정 시드 10개에서 관문 후보지 쌍 280개를 비교했다. 전 성계가 아군인 최저 비용 조건에서도 262쌍은 관문이 더 저렴했고, 173쌍은 일반 항로로 기본 행동력 2를 초과했다. 최장 일반 경로는 행동력 4.2였다.
- 장거리 함대 재배치와 적 관문 점령 이후 연속 공세가 주는 이득은 AI 문명이 있는 장기 캠페인에서 추가로 검증한다.
