# 공통 UI와 은하 지도

> 요약: 메뉴·자원·팝업·은하 지도 화면과 입력
> 상태: 확정
> 연관: [[systemview]], [[surface]], [[researchscreen]]


## 8. 화면과 저장 — 현재 적용

- 게임 전체 UI의 텍스트는 드래그로 선택되지 않도록 처리하여 지도 이동과 브라우저의 글자 선택이 충돌하지 않게 한다.

### 메인 시작 화면

- 제공된 `MainMenu_DEC.png`를 `assets/backgrounds/main-menu.png`에 보관하고 전체 화면 배경으로 사용한다.
- 오른쪽 행성과 함대가 드러나도록 제목과 메뉴를 왼쪽 여백에 배치한다. 메뉴는 새 게임, 불러오기, 튜토리얼(준비 중·비활성), 종료 순서다.
- 반투명한 어두운 버튼을 사용하며 기본 상태에서는 특정 메뉴를 강조하지 않는다. 활성 버튼에 마우스를 올렸을 때만 푸른 강조색과 오른쪽 화살표(→)를 표시한다. 좁은 화면에서는 하단에 메뉴를 배치하고 배경에 어두운 그라데이션을 적용해 글자를 읽기 쉽게 한다.

### 8.1 은하 지도

- 참고 시안에 맞춰 어두운 반투명 패널과 얇은 금속색 테두리로 UI를 구성한다. 기존 은하 배경 일러스트를 유지한다.
- 상단은 문명 이름(기본 종족은 테라 문명), 개척 성계 수·턴, 자원별 보유량·턴당 순증감, 진행 기록·알림·도움말·메뉴 순이다. 자원별 생산·소모 상세 툴팁을 유지한다.
- 왼쪽 탐색 버튼은 은하 지도·연구·거주 가능 행성·전투 함선·승리 순이다. 연구는 5분야·0~V단계의 방사형 화면을 열고, 전투 함선은 [[combatui]]의 함대 관리 창을 연다. 알림은 최근 진행 기록에 남은 연구 완료를 표시하고 도움말은 빈 팝업이다.
- 거주 가능 행성 목록은 탐사 완료한 행성만 표시하며 소유 행성은 관리 화면, 미개척 행성은 해당 성계 화면으로 이동한다. 미확인 행성 정보를 목록으로 공개하지 않는다.
- 자원 6종과 탐색 아이콘은 `assets/icons/`의 독립 SVG로 관리한다. 자원 상세, 행성 건설·운영, 연구, 조선소, 함선 설계, 전투 테스트에서 자원 수치를 아이콘과 함께 표시한다. 공통 표시 코드는 `src/resource-ui.js`에서 관리한다.

- 배경은 제공된 `Map_Background_4_DEC.png`를 `assets/backgrounds/galaxy-map.png`에 보관해 사용한다. 성계·항로와 별도 화면 층에 표시하여 지도 확대·축소 시 배경 크기를 유지한다.
- 전체 항성계·항로 영역(표식 여백 포함)의 가로·세로 각각 2배, 면적 약 4배를 이동 경계로 사용한다. 화면이 경계를 벗어나지 않도록 이동과 최소 배율을 제한한다. 배경은 화면 중앙에 고정하여 지도 이동·확대·축소에 따라 위치나 크기가 바뀌지 않는다. 일러스트 양 끝을 지도 이동 경계에 맞추는 연동은 사용하지 않는다. 어두운 가장자리와 성계 이름 외곽선으로 전경의 가독성을 유지한다.
- 좌측 하단에는 함선 패널을 배치한다. 선택 시 모델 미리보기·이름·위치·행동력과 이동 버튼을 표시하며, 탐사선에는 개별 탐사, 개척선에는 개척 버튼을 표시한다. 미선택 시 함선 제목과 빈 패널을 유지한다. '선택한 항성계' 패널과 고정 성계 선택 테두리는 제거했다.
- 진입 가능한 성계에 마우스를 올리면 테두리를 표시한다. 이동 선택 중에는 이동 가능 여부를 기준으로 강조한다.
- 은하 지도 함선 아이콘은 0.55배 배율을 유지하며 탐사선·개척선의 실루엣과 색상을 구분한다. 성계는 발광 중심·얇은 원형 표식·이름표로 표시하고 개척 성계에는 황금색 강조를 사용한다. 성계 간 거리는 기존 지도 생성 규칙을 따른다.
- 방문해 구성을 확인한 성계에 거주 가능 행성이 있으면 파란 행성 표식을 붙이고, 2개 이상이면 개수도 표시한다.
- 미확인 성계의 진입 안내는 '탐사선 도착 후 진입 가능'이다.
- 고대 유적·잔해는 주황색, 블랙홀은 보라색이다. 탐사 완료 후에도 같은 색 계열을 유지하고 점선에서 밝은 실선으로 바꾼다.

- 게임 내 모달·우클릭 명령·메뉴·자원 툴팁은 함선 패널과 같은 짙은 반투명 배경과 금색 테두리로 통일한다. 브라우저 기본 확인·경고 대화상자는 브라우저 표시를 따른다.
