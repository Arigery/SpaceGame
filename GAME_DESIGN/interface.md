## 8. 화면과 저장 — 현재 적용

- 기본 화면에는 행동명·현재 상태·핵심 수치를 표시한다. 익숙한 기호와 기존 자원 아이콘을 활용하고, 기호만 쓰는 버튼에는 접근 가능한 이름을 붙인다.
- 보조 조작법과 계산 기준은 툴팁이나 접을 수 있는 상세로 옮긴다. 행성 자원 수지의 생산·소비 내역은 마우스와 키보드 포커스로 확인할 수 있다. 실행 조건, 비용, 경고, 스토리는 필요한 화면에 표시한다.

- 게임 전체 UI의 텍스트는 드래그로 선택되지 않도록 처리하여 지도 이동과 브라우저의 글자 선택이 충돌하지 않게 한다.

### 공통 HUD와 화면 전환

- PC 화면 검증은 1920×1080을 기본, 1280×720을 최소로 삼는다. 상단 자원은 종류·보유량·턴당 순증감 순으로 읽히도록 숫자의 크기와 폭을 구분한다.
- 공통 탐색은 왼쪽에 둔다. 은하 지도는 오른쪽 아래에 금속색 이중 테두리의 원형 다음 턴 버튼을 사용하고, 성계는 같은 위치에 가로형 버튼을 사용한다. 행성 관리의 복귀와 다음 턴은 상단 조작 줄에 고정하며 본문만 스크롤한다.
- 지도와 성계의 미선택 함선 영역은 제목 크기로 접고, 선택하면 명령 영역을 펼친다. 행성 관리에서는 함선 명령 영역을 표시하지 않는다.
- 모달이 열리면 배경 조작과 포커스를 잠근다. 일반 모달은 닫기 또는 Esc로 닫고 진입점에 포커스를 돌려준다. 사건과 전투의 필수 선택 및 기존 Esc 처리 우선순위를 유지한다.
- 청흑색을 기본으로 하고, 금색 계열은 주요 조작과 포커스에 사용한다. 자원·항로·전투 상태에 의미가 있는 기존 색상과 아이콘은 유지한다. 공통 기준을 공유하되 화면의 주된 행동에 맞게 배치를 결정한다.

### 메인 시작 화면

- 제공된 `MainMenu_DEC.png`를 `assets/backgrounds/main-menu.png`에 보관하고 전체 화면 배경으로 사용한다.
- 오른쪽 행성과 함대가 드러나도록 문장 아이콘·제목·메뉴를 왼쪽에 배치한다. 새 게임과 불러오기를 먼저 표시하고, 아래에는 튜토리얼(준비 중·비활성)과 전투 테스팅, 하단에는 설정과 종료를 둔다.
- 새 게임 화면은 테라 문명 카드, 선택 입력인 맵 시드, 메인 메뉴 복귀와 게임 시작을 표시한다. 메인과 게임 내 메뉴의 설정은 같은 창을 열고 빠른 이동을 즉시 적용한다. 시드와 전체 지도 도구는 게임 내 메뉴에 둔다.
- 저장·불러오기는 [[saves]]의 5개 슬롯을 공통 창으로 표시하며 문명명·턴·저장 시각을 읽을 수 있다. 가장 최근에 저장한 슬롯은 위치를 유지한 채 강조한다.

### 8.1 은하 지도

- 참고 시안에 맞춰 어두운 반투명 패널과 얇은 금속색 테두리로 UI를 구성한다. 기존 은하 배경 일러스트를 유지한다.
- 상단은 문명 이름(기본 종족은 테라 문명), 개척 성계 수·턴, 자원별 보유량·턴당 순증감, 진행 기록·알림·도움말·메뉴 순이다. 연구력은 보유량·턴당 순증감과 연구 진행 상태를 표시한다. 나머지 자원의 상세에는 해당 자원에 적용되는 항목을 표시한다. 채굴 기지는 에너지·광물, 인구 소비는 식량·소비재 상세에 표시한다.
- 왼쪽 탐색 버튼은 은하 지도·연구·거주 가능 행성·전투 함선·승리 순이다. 연구는 5분야·0~V단계의 방사형 화면을 열고, 전투 함선은 [[combatui]]의 함대 관리 창을 연다. 알림은 최근 진행 기록에 남은 연구 완료를 표시하고 도움말은 빈 팝업이다.
- 거주 가능 행성 목록은 탐사 완료한 행성만 표시하며 소유 행성은 관리 화면, 미개척 행성은 해당 성계 화면으로 이동한다. 미확인 행성 정보를 목록으로 공개하지 않는다.
- 자원 6종과 탐색 아이콘은 `assets/icons/`의 독립 SVG로 관리한다. 자원 상세, 행성 건설·운영, 연구, 조선소, 함선 설계, 전투 테스트에서 자원 수치를 아이콘과 함께 표시한다. 공통 표시 코드는 `src/resource-ui.js`에서 관리한다.

- 배경은 제공된 `Map_Background_4_DEC.png`를 `assets/backgrounds/galaxy-map.png`에 보관해 사용한다. 성계·항로와 별도 화면 층에 표시하여 지도 확대·축소 시 배경 크기를 유지한다.
- 전체 항성계·항로 영역(표식 여백 포함)의 가로·세로 각각 2배, 면적 약 4배를 이동 경계로 사용한다. 화면이 경계를 벗어나지 않도록 이동과 최소 배율을 제한한다. 배경은 화면 중앙에 고정하여 지도 이동·확대·축소에 따라 위치나 크기가 바뀌지 않는다. 일러스트 양 끝을 지도 이동 경계에 맞추는 연동은 사용하지 않는다. 어두운 가장자리와 성계 이름 외곽선으로 전경의 가독성을 유지한다.
- 좌측 하단에는 함선 패널을 배치한다. 선택 시 모델 미리보기·이름·위치·행동력과 이동 버튼을 표시하며, 탐사선에는 개별 탐사, 개척선에는 개척 버튼을 표시한다. '선택한 항성계' 패널과 고정 성계 선택 테두리는 제거했다.
- 일반 화면의 성계 표식은 원형이다. 함대는 성계 이름 아래에 육각 배지로 배치하고, 한 성계에 여러 함대가 있으면 행 단위로 간격을 두어 각각 선택할 수 있다. 선택한 함대에는 금색 윤곽을 표시한다.
- 이동 명령 중에는 도달 가능한 목적지를 점선 원으로, 그곳까지 쓰이는 항로를 은은한 선으로 표시한다. 목적지에 마우스를 올리거나 키보드 포커스를 두면 실제 이동 경로를 밝게 표시한다. 일반 항로는 금빛, 개척 연결 항로는 청록색을 사용한다.
- 목적지 옆에 소모 행동력을 표시한다. 공동 이동 비용이 함대마다 다르면 지도에는 범위를, 목적지 상세에는 함대별 비용을 표시한다. 표시값과 경로는 기존 [[movement]] 및 [[fleets]]의 이동 판정을 따른다.
- 은하 지도 함선 아이콘은 0.55배 배율을 유지하며 탐사선·개척선의 실루엣과 색상을 구분한다. 성계는 발광 중심·얇은 원형 표식·이름표로 표시하고 개척 성계에는 황금색 강조를 사용한다. 성계 간 거리는 기존 지도 생성 규칙을 따른다.
- 방문해 구성을 확인한 성계에 거주 가능 행성이 있으면 파란 행성 표식을 붙이고, 2개 이상이면 개수도 표시한다.
- 미확인 성계의 진입 안내는 '탐사선 도착 후 진입 가능'이다.
- 고대 유적·잔해는 주황색, 블랙홀은 보라색이다. 탐사 완료 후에도 같은 색 계열을 유지하고 점선에서 밝은 실선으로 바꾼다.

- 게임 내 모달·우클릭 명령·메뉴·자원 툴팁은 함선 패널과 같은 짙은 반투명 배경과 금색 테두리로 통일한다. 브라우저 기본 확인·경고 대화상자는 브라우저 표시를 따른다.
