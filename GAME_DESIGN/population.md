# 인구와 생산력

> 요약: 성장·수용량·배치·소비와 건설 생산력
> 상태: 논의중
> 연관: [[start]], [[economy]], [[construction]]


- 건설 생산력: `(정수 인구 + 중심지 배치 인구) × max(0, 1 + 건설 영구 보정 합)`. 공사 진행과 예상 턴 표시가 같은 함수를 사용한다. 건설 비용·필요 생산력·광물/가스 타이머는 변경하지 않는다.
- 인구 성장: `(기본 성장 + 가동 의료시설 성장) × max(0, 1 + 성장 영구 보정 합)`. 기존 수용량 제한을 유지한다. 영구 불이익은 시간이 지나도 제거하지 않는다.
### 4.2 인구와 행성 생산력

| 항목 | 현재 기준 |
| --- | --- |
| 초기 인구 | 모행성 6 / 신규 개척 3 (확정) |
| 기본 최대 인구 | 8 |
| 기본 인구 성장 | 0.5/턴 |
| 작업자·소비 계산 인구 | 현재 인구의 정수 부분 |
| 행성 생산력 | 정수 전체 인구 + 중심지 배치 인구 /턴 (확정) |
| 인구 소비 | 1명당 식량 0.5, 소비재 0.25/턴 |
| 공용 구역 확장 | 단계당 최대 인구 +1, 중심지 배치 한도 +1 |

- 특화 건물 등에 배치한 인구도 전체 인구에 포함되므로 생산력 계산에서 빼지 않는다.

- 소비재 추가 소비는 소유한 거주 가능 행성 수에 비례하며 최대 30%다. 현재 계산은 다음과 같다.

```text
expected = max(2, 성계 수 × 0.42 / 4)
penalty = min(0.30, 0.15 × max(0, 소유 거주 행성 수 − 1) / (expected − 1))
인구 소비재 소비 = 정수 인구 × 0.25 × (1 + penalty)
```

- 인구·생산·소비의 조정 가능한 수치는 별도 JSON에서 관리한다.
