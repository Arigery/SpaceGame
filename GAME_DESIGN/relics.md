# 고대 유적

> 요약: 기존 유적 8곳의 연구 잠금·문명별 조사·최초 획득 효과
> 상태: 확정
> 연관: [[discoveries]], [[survey]], [[victory]], [[research]], [[saves]]

- 새 은하의 기존 고대 유적·잔해 8곳에 유적 유형을 시드 기반으로 하나씩 배정한다. 위치와 행성 구성은 유지한다. 이전 저장은 기존 발견·조사 기록을 보존한다.
- 행성 조사 기술 I로 6곳, II로 고급 2곳을 해금한다. 탐사선이 현지에서 행동력 1을 사용한다. 유적의 연구 잠금은 행성 탐사·개척 조건에 영향을 주지 않는다.
- 문명별로 유적당 조사 기록 1개를 획득한다. 최초 조사 문명만 영구 효과를 받으며 소유권 이전 이후에도 효과를 유지한다. 후발 문명은 동일한 과학 승리 조사 기록을 얻는다.
- 과학 승리 탭에 문명별 조사 기록과 내 유물 효과를 표시한다. 목표 기록은 5개이며 최종 프로젝트·승리 판정은 [[victory]]의 후속 범위다.

| 유적 | 최초 조사 영구 효과 |
| --- | --- |
| 고대 채굴 시설 | 광물 정상 생산 +8% |
| 고대 에너지 시설 | 에너지 정상 생산 +8% |
| 고대 생태 연구소 | 식량 정상 생산 +8% |
| 고대 산업 시설 | 신소재 정상 생산 +8% |
| 고대 생산 시설 | 소비재 정상 생산 +8% |
| 고대 천체 관측소 | 연구력 정상 생산 +8% |
| 고대 의료 시설 | 인구 성장률 +8% |
| 고대 조선 시설 | 조선소 민간선·군함 건조 진행량 +8% |

- 생산·성장 보정은 기존 보정군에 더한다. 즉시 지급이나 지역형 경이의 고정 산출·함대 수리·유지비는 증폭하지 않는다.
- 조선소는 남은 작업량과 소수점 진행량을 저장한다. 효과가 있어도 짧은 작업은 같은 턴에 완료될 수 있다.
- 수치는 `data/exploration.json`의 `relics`에서 관리한다.
