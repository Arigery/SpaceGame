### 4.3 연구 시스템 — 확장 가능한 기본 구조 (2026-11-15)

- 이전 55개 기술, 시대별 고정 개수, 복잡한 AND/분야 교차 조건과 정점 기획은 **대체된 초안**이다. 최종 기술 이름·효과·개수로 취급하지 않는다. 이전 180턴 시뮬레이션 수치도 새 트리의 밸런스 근거로 사용하지 않는다. 현재는 콘텐츠 완성보다 시스템 연결을 위한 구조를 구현한다.

#### 연구의 세 가지 유형과 단계

1. 신규 콘텐츠 해금(`unlock`): 새 건물·함선·시설·행동 사용.
2. 기존 시스템 확장(`expansion`): 기존 시설의 새 기능·선택지 추가.
3. 수치 강화(`enhancement`): 생산·성장·건설·효율 강화.

- 연구 단계는 0(기원), I(기초), II(초기 발전), III(중반), IV(고급), V(최상위)다. 연구 노드의 상태를 구분하는 `nodeType`은 위 콘텐츠 유형과 별도다.

| 노드 종류 | 비용·진행 | 선행·완료 처리 |
| --- | --- | --- |
| 기원 `origin` | 비용 0, 연구 불가 | 시작부터 항상 완료, 기존 행동에 잠금 추가 없음 |
| 임시 연구 `research` | 명시된 시험 비용으로 선택·투입·완료 | 실제 선행 판정 대상 |
| 미설계 `placeholder` | 비용 null, 효과 없음, 비활성 | 시작·완료·선행 대상 모두 제외 |

- 기원은 **성간 항행 / 행성 탐사 / 행성 개척 / 기초 건설 / 자원 채굴**의 5개 기본 기술이다. 어느 특정 분야의 신규 해금으로 오해하지 않도록 중앙 공통 기원 영역에 함께 배치하며, 5분야가 이 공통 기반을 둘러싼다. 이동·탐사·개척·기본 건설·채굴의 기존 조건은 변경하지 않는다.

#### 분야와 현재 임시 배치

- 탐험·과학 / 경제·운영 / 개척·건설 / 군사 / 외교를 유지한다. 분야별 개수와 단계별 개수는 고정하지 않으며 총 55개 제한도 없다. 현재 초기 배치는 **기원 5개 + 임시 연구 15개 + 빈 슬롯 25개**다. 이것은 현 시점의 배치량이며 향후 규모 기준이 아니다.

- 임시 연구는 수치 강화 12개(군사·외교 미연동 각 1개 포함), 부속 해금 3개다. 실제 효과를 적용하는 것은 13개, 효과가 없는 진행 예시는 2개다. 부속 해금은 이미 존재하는 설치 규칙을 유지하기 위한 예외이며 새로운 콘텐츠를 추가하지 않는다. 비용은 기존 기술의 시험 비용을 유지하고 군사·외교 예시는 기존 기초 비용 30을 사용한다. 최종 비용·효과 밸런스는 후속 상세 설계에서 정한다.

- 호환성을 위해 일부 이전 ID를 유지한다. ID 문자열에 포함된 옛 분야·시대 숫자가 아니라 `field`와 `era`가 현재 배치를 결정한다. 정비 자동화(`eco_2_3`)는 개척·건설 I단계로 옮겼으며 기존 효과 +10%와 시험 비용 120은 유지한다.

- 각 분야 I~V단계에 빈 슬롯을 우선 하나씩 배치한다. 빈 슬롯의 이름은 미설계 연구이며 비용·효과를 임의로 정하지 않는다. 추후 데이터에서 `nodeType: research`, 콘텐츠 유형, 비용·효과·선행을 지정하면 같은 슬롯 ID로 실제 연구가 된다. 빈 슬롯에 부정확한 연구 진행도나 완료 ID가 저장되어도 불러오기에서 제외한다.

- 현재 선행은 같은 분야의 단순 연결만 사용한다. 부속 I→II→III, 조사 기술 I→II 등의 연결을 유지하며 분야 간 교차 조건·정점 전용 조건은 없다. 데이터 검증은 존재하지 않는 선행, 빈 슬롯 선행, 순환, 도달 불가, 잘못된 비용을 거부한다. 기술 총수·분야별 개수·동일 단계의 동일 비용은 강제하지 않는다.

#### 진행·경제·저장 호환

- 한 번에 한 연구를 진행한다. 중단·전환 시 진행도를 보존하고 자원 정산 후 `min(연구력 재고, 남은 필요량)`을 투입한다. 턴당 완료는 최대 하나이며 잔량은 재고로 남는다.
- 진행 연구 없이 가능한 연구가 있으면 턴 정산 전에 연구 창을 연다. 시작하면 턴을 계속 처리하고 닫으면 정산을 취소한다. 기원과 빈 슬롯은 이 판정에서 제외한다.
- 예상 턴은 비축량과 현재 수입 및 실제 정산의 반올림을 반영한다. 완료 효과는 완료 턴의 경제·공사·성장에 소급 적용하지 않는다.
- 탐사 연구 보상·레벨은 현재 임시 기술에서 도출한다. 탐험 이벤트 확률·스토리·신호·개척 조건은 변경하지 않는다. pending 이벤트의 발견 시 레벨·난수·결과를 유지한다.
