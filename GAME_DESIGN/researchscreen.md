# 연구 화면

> 요약: 분야별 부채꼴과 기원·활성·미설계 노드 표시
> 상태: 확정
> 연관: [[research]], [[interface]]


#### 연구 화면

- 5분야를 72° 부채꼴로 분리하며 탐험·과학은 청색, 경제·운영은 녹색, 개척·건설은 황금색, 군사는 붉은색, 외교는 보라색 계열의 은은한 배경·경계·제목을 쓴다. 중앙 공통 영역에 기원과 완료 표시된 기본 기술 5개, 바깥 I~V 고리에 연구를 배치한다.

- 좌표는 데이터의 분야·단계·같은 고리 내 순서와 개수에서 계산한다. 단계 표식 I~V는 두 분야 사이의 한 축에 정렬한다. 지도 위에는 5개 분야와 연구 가능 수를 표시하며, 분야를 누르면 해당 부채꼴을 강조한다.
- 연구 가능은 금빛 마름모와 이름, 진행 중은 청색 막대 표식, 완료는 체크, 잠김은 자물쇠로 구분한다. 미설계 슬롯은 옅은 점선으로 보이고 기원은 기본 보유로 표시한다. 두 유형 모두 시작 버튼이 없다.
- 선택한 잠긴 기술의 이름이 선행 기술명과 겹치면 선택한 이름의 표시 위치만 조정한다.
- 오른쪽에는 현재 연구와 선택한 기술의 상세를 표시한다. 상세에서 분야·단계·상태와 효과를 먼저 보여주며, 연구 진행량·예상 완료를 함께 표시한다. 잠긴 기술은 선행 조건을 효과보다 위에 배치한다. 공통 정산 정보는 펼쳐 보고, 연구 시작·전환은 상세 하단에서 조작한다.

- 기존 휠 확대·드래그·핀치·키보드 탐색, 상세 패널, 선행 확인, 현재 연구 헤더, 진행 기록·완료 알림을 유지한다. 군사·외교 임시 연구에는 ‘실제 효과 미적용’을 명시한다. 현재 임시 연구를 전부 마치면 빈 슬롯 때문에 턴 종료 연구 선택 창이 반복되지 않는다.
