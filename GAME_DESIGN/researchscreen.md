# 연구 화면

> 요약: 분야별 부채꼴과 기원·활성·미설계 노드 표시
> 상태: 확정
> 연관: [[research]], [[interface]]


#### 연구 화면

- 5분야를 72° 부채꼴로 분리하며 탐험·과학은 청색, 경제·운영은 녹색, 개척·건설은 황금색, 군사는 붉은색, 외교는 보라색 계열의 은은한 배경·경계·제목을 쓴다. 중앙 공통 영역에 기원과 완료 표시된 기본 기술 5개, 바깥 I~V 고리에 연구를 배치한다.

- 좌표는 데이터의 분야·단계·같은 고리 내 순서와 개수에서 계산하며 노드 수가 늘어도 각 분야의 부채꼴 안에 배치한다. 기본 틀 수준으로 유지하고 복잡한 연결선·정점 연출을 추가하지 않는다. 완료/진행/가능/잠김을 구분하고 빈 슬롯은 어두운 점선으로 표시한다. 빈 슬롯은 설명을 확인할 수 있지만 시작 버튼은 없다. 기원에는 비용·예상 턴 진행도를 표시하지 않는다.

- 기존 휠 확대·드래그·핀치·키보드 탐색, 상세 패널, 선행 확인, 현재 연구 헤더, 진행 기록·완료 알림을 유지한다. 군사·외교 임시 연구에는 ‘실제 효과 미적용’을 명시한다. 현재 임시 연구를 전부 마치면 빈 슬롯 때문에 턴 종료 연구 선택 창이 반복되지 않는다.
