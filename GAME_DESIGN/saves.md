# 저장과 호환

> 요약: 게임 상태 보존·구버전 이관·효과 중복 방지
> 상태: 확정
> 연관: [[research]], [[stories]], [[questions]]

- 원문에 서로 다른 연구 레벨 이관 설명이 존재한다. [[questions]] Q-01을 확인하며 이번 이관에서는 규칙을 재결정하지 않는다.

- 환경이 없는 기존 저장은 이미 선택된 환경별 이벤트가 있으면 그 환경을 채택하여 기존 선택·판정 난수를 유지한다. 그 외는 시드로 환경을 배정한다. 이미 저장된 환경과 진행 단계는 유지한다.
- 선택 단계, A/B 방향, 고정 난수, 조사 방식, 판정 시 연구 레벨·확률·배율, 결과·적용 효과·확인 대기를 저장한다. 결과 적용은 pending 상태에서 한 번만 가능하다. 불러오기로 난수를 재추첨하거나 자원을 중복 지급하지 않는다.
- 기존 저장의 아직 미확인인 임시 이벤트는 새 조사 흐름으로 이어지고, 이미 확인한 임시 이벤트는 다시 열지 않는다. 기존 일반 이상현상·거주 행성별 발생 판정과 효과는 유지한다. 여러 팝업은 기존 순차 표시를 따른다.
- 저장 스키마는 `research.version: 2`다. `completed`, `current`, `progress`와 이전 효과 보존용 `legacyCompleted` ID 목록을 저장한다. 경제 효과 자체는 누적 저장하지 않는다.
- 유지한 기술 ID의 완료·진행도는 보존한다. 이미 투자한 진행 연구는 선행 재배치 때문에 강제 취소하지 않고 계속할 수 있다. 중단 후 새로 시작하는 경우는 새 선행 조건을 따른다.
- 삭제한 완료 기술은 `legacyCompleted`로 옮겨 기존 효과를 유지한다. 효과 정의는 `research.json`의 `legacyDefinitions`에 격리하며 새 게임 트리·선행·연구 가능 목록에 넣지 않는다. 이 데이터는 이전 저장 호환용이지 확정 연구 콘텐츠가 아니다.
- 삭제한 미완료 기술에 투자한 연구력은 알려진 이전 비용 한도에서 재고로 한 번 반환하고 진행 항목을 제거한다. 반복 불러오기에서 중복 반환되지 않는다. 알 수 없는 ID는 안전하게 제외한다.
- 기존 `explorationResearchLevel`만 있는 저장은 동일 레벨의 조사 기술 완료로 옮긴다. 새 선행을 보상처럼 추가 완료하지 않는다. 이전 저장의 설치 부속을 삭제하거나 기본 경제 수치를 바꾸지 않는다.

### 8.4 저장 및 호환

- 브라우저 localStorage에 5개 슬롯으로 저장한다. 키는 space_civilization_slots_v5다.
- 게임 메뉴에서 저장·불러오기를 제공하며 덮어쓰기와 미저장 진행 소실을 확인한다. 메인 메뉴에서는 불러오기를 제공한다. 튜토리얼은 저장·불러오기를 제공하지 않는다.
- 기존 인구·자원·시설·탐험 상태를 유지한다. 옛 저장의 탐사 완료 성계는 내부 대상도 완료한 것으로 취급한다.
- 성계 이름 공개, 행성 구성 관측, 개별 대상 탐사, 반대편 항성 확인, 함선 내부 위치·방향은 게임 상태에 저장한다. 빠른 이동 설정은 브라우저에 별도로 저장한다.
- 옛 저장의 진행 중 공사는 남은 시간을 유지한다. 새 공사는 착공 당시 비용·필요 생산력·진행률 또는 고정 타이머를 저장한다. 이미 지불한 비용은 소급 차감하지 않는다.
- 건물 유지비는 현재 데이터의 알려진 금액을 적용한다.
- 파일 경로·브라우저가 달라지면 같은 저장 공간 사용을 보장하지 않는다. 클라우드 동기화와 세이브 내보내기는 후속 항목이다.
