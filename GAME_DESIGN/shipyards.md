## 조선소와 생산
- 모성계는 기본 조선소를 보유한다. 추가 소유 성계의 조선소는 광물 80·3턴이다.
- 성계당 조선소 1개, 완공된 조선소에서 함선 건조·장갑 수리를 하나의 순차 대기열로 처리한다.
- 예약 시 자원을 한 번 지불하며 비용·조립 능력치·기간·배치 대상 함대를 작업에 저장한다.
- 대기 중 설계 변경·밸런스 변경·저장 복원으로 예약된 작업의 비용을 재청구하거나 능력치를 재계산하지 않는다.
- 각 조선소는 턴당 첫 작업만 1턴 진행한다. 완공 턴에 다음 작업까지 진행하지 않는다. 여러 조선소는 병렬 진행한다.
- 조선소 자체가 완공되는 턴에는 군함을 생산하지 않는다. 소유권을 잃으면 해당 조선소 작업은 정지한다.
- 완공 함선은 지정한 같은 성계 소유 함대로 배치한다. 함대 이동·해산·정원 부족 시 예비 함선으로 배치한다.
- 새 함선의 장갑·보호막은 최대치, AP는 현재 연구를 반영한다. 예비 함선도 유지비를 지불한다.
- 취소·환불 기능은 아직 제공하지 않는다. 기존 행성 건설의 취소 규칙을 변경하지 않는다.
- 함대 메뉴 → 조선소·생산·수리에서 성계 선택·예약·예상 완료 턴·수리·대상 함대 지정을 제공한다.
- 이전 무료 TEST 생성 도구는 기본 비활성화했다. 정상 플레이는 조선소를 사용한다.
- 보급망·연료망은 추가하지 않는다.

| 호위함 | 20 | 2 | 1 | 0.2 |

- 관리 위치: `data/combat.json` hulls/buildTurns·economyBenchmark·buildCost·upkeep, modules, shipyards.
- 표준 비용·유지비의 60%는 선체, 40%는 표준 슬롯 수로 나눈 모듈별 비용이다.
- 기본 에너지·운동탄 무기 및 기본 방어 모듈은 해당 규격의 같은 비용 지분을 사용한다. 모듈을 비우면 해당 지분이 빠진다.
- 기동 엔진은 표준 엔진 비용·유지비의 1.3배다. 무기 단계 배율은 아래를 따른다.
- 완공된 함선의 저장된 조립 유지비를 기존 자원 내역의 함선 소비에 합산한다. 미완공 함선은 제외한다.
- 건조 완료 전 턴에 유지비를 소급 부과하지 않는다. 완공 다음 턴의 정산부터 발생한다.
- 기존 자원 0 하한은 유지한다. 부족 시 자동 폐함·정지·부채 규칙을 추가하지 않는다.
- 이미 존재하는 구버전 군함은 저장된 능력치·비용·유지비 스냅샷을 보존한다. 새로 건조하는 함선부터 현재 비용을 적용한다.

## 장갑 수리
- 완공된 소유 조선소와 같은 성계의 손상된 소유 함선만 예약할 수 있다.
- 신소재 비용 = 올림(저장된 건조비 × 장갑 손상 비율 × 0.25), 최소 1.
- 기간 = 올림(함급 건조 턴 × 손상 비율), 최소 1턴.
- 예약 시 당시의 손상량·비용·기간을 고정하고 자원을 지불한다. 수리 대기·진행 중인 함선을 포함한 함대는 이동할 수 없다.
- 편성 해제는 가능하지만 수리 잠금은 함선에 남는다. 중복 수리 예약은 불가하다.
- 완료 시 예약한 장갑 손상량만 회복한다. 이후 전투로 생긴 추가 손상은 무료로 수리하지 않는다.
- 보호막 회복은 포함하지 않는다. 수리 중에도 유지비를 청구한다.
- 격파된 함선의 수리 작업은 종료되며 환불하지 않는다.

## 군사 연구 해금
- 초계함과 그 기본 반응로·표준/기동 엔진·1단계 무기·보호막·장갑은 시작부터 사용한다.
- 후속 함체 연구는 해당 규격의 기본 모듈도 함께 사용할 수 있게 한다. 새 기원 노드는 추가하지 않는다.
- 기존 5분야·기원·빈 슬롯·진행도·선행 판정은 유지하고 군사 분야에 실제 해금 연구를 추가한다.

- 같은 계열의 명중·발사 간격·사거리·보호막/장갑 배율은 유지한다. 전력 초과 설계는 여전히 거부한다.
- 연구 완료 여부로만 해금한다. 진행 중·빈 슬롯은 해금에 영향을 주지 않는다.
- 상위 무기는 해당 함체와 무기 계열 연구를 모두 요구한다. 에너지 연구로 운동탄을 해금하지 않는다.
- 설계창에서 잠긴 구성은 열람할 수 있지만 잠긴 모듈 선택은 비활성화한다. 잠긴 설계의 생산은 서버 없는 로컬 공통 로직에서도 거부한다.
- 연구 완료는 기존 completed에 저장한다. 저장 복원 시 선행 기술을 임의로 추가하거나 이미 건조된 함선을 제거하지 않는다.

## 초기 경제와 180턴 기준 점검
- 실제 초기 순수입: 에너지 +7, 광물 +8.5, 신소재 +0, 연구력 +5/턴. 초기 신소재 100으로 초계함을 바로 건조할 수 있다.
- 장기 생산에는 신소재 특화가 필요하다. 기본 작업자 1명 생산 +5 기준, 초계함 12는 유지비 전 생산 약 2.4턴분이다.
- 예시 50점 함대는 건조비 590, 총 조선소 작업 45턴, 유지비 에너지 25·신소재 6.3/턴이다.
- 8~9개 동일 예시 함대는 유지비만 에너지 200~225·신소재 50.4~56.7/턴이다. 고도 산업화의 목표이며 시작 경제로 유지할 수 있다는 뜻은 아니다.
- 함체 연구 총 1,300: 연구력 5/턴이면 260턴분, 20/턴이면 65턴분. 무기 2계열 추가 총 940이며 연구 생산 성장이 필요하다.
- 180턴 테스트: 신소재 초기 100·생산 5/턴·10턴마다 초계함 1척 예약 조건에서 18척 완료·중복 차감 없음·재고 양수 확인.
- 위 시험은 경제 경계 확인이며 전체 180턴 캠페인 승률·최종 밸런스 검증이 아니다. 수치는 추후 조정한다.

## 저장·검증
- `shipyardVersion: 1`, 성계별 shipyard.remaining/queue에 지불 상태·진행도·조립 스냅샷을 저장한다. 수리는 함선 repairJobId로 연결한다.
- 구버전 저장은 소유 모성계에 기본 조선소를 추가하고 기존 함선·시설·자원은 보존한다.
- 비용 1회 지급, 3턴 완공, 순차 대기열, 함대/예비 배치, 수리와 이동 잠금, 유지비 시점, 선행·완료 연구·저장 복원·UI 핸들러를 코드 테스트한다.
