# 자원 부족 패널티

> 요약: 자원별 연속 부족, 2단계 패널티와 30턴 비교
> 상태: 논의중
> 연관: [[economy]], [[construction]], [[combat]], [[saves]]

## TEST v1

| 부족 자원 | 1단계 — 첫 부족부터 | 2단계 — 연속 4번째 부족부터 추가 |
| --- | --- | --- |
| 에너지 | 건물 생산 −5% | 군함 전투 능력 −15% |
| 광물 | 추가 효과 없음 | 에너지 소모 +20% |
| 식량 | 인구 성장 −30% | 소비재 소모 +20% |
| 소비재 | 연구력 생산 −20% | 식량 소모 +20% |
| 신소재 | 군함 전투 능력 −10% | 광물 유지비 +20% |

- 재고와 해당 턴 생산을 합해 필수 소모를 감당할 수 없는 경우에만 부족으로 판정한다. 재고 0이어도 수급이 균형이면 정상이다. 연구력은 판정 대상에서 제외한다.
- 기존 턴 정산은 시작 시점의 효과를 적용한 수급으로 한 번 계산한다. 정산에서 부족을 확인하면 같은 시점에 상태를 갱신한다. 새 효과는 즉시 표시하며 이후 교전 및 다음 경제 정산에서 사용한다.
- 1단계는 부족 동안 유지하고 회복 정산에서 제거한다. 2단계 지속 시간은 3턴이며, 연속 4번째 부족부터 부족 정산마다 3으로 갱신한다. 회복하면 상태는 2→1→만료로 줄어든다. 회복 후 재발은 연속 1턴부터 다시 세고, 이전 2단계의 여파는 원래 만료 시점까지 남는다.
- 부족 상태·지속 시간은 자원별로 저장한다. 이전 저장은 효과가 없는 상태로 시작한다. 재고 0 하한은 기존과 같다. 가격·조선소 운영·수리·건설 시간은 기존 규칙을 따른다.

## 적용 범위와 결합 기준

- 에너지는 거주 행성의 중심지와 특화 건물 생산을 낮춘다. 광산·가스 채집소는 별도로 정산한다. 소비재 부족의 연구 페널티도 같은 생산 단계에 더한다. 두 효과가 겹친 TEST v1 연구력 생산은 −25%다. 소비재·신소재에 들어가는 광물은 실제 생산량 기준으로 같이 변한다.
- 소모 보정은 해당 자원의 기존 턴당 소모를 계산한 뒤 곱한다. 신소재 부족의 광물 보정은 유지비에 적용한다. 건설 선불과 특화 생산 투입에는 기존 비용을 적용한다.
- 군함 전투 능력의 TEST 적용 범위는 무기 피해량·전술 속도·회피다. 에너지와 신소재 효과가 겹치면 합산하고, 교전 시작 시 스냅샷에 한 번 반영한다. 전략 AP·장갑·보호막·사거리·사격 간격은 기존 수치를 사용한다. 진영별 경제가 적용된 플레이어 군함을 대상으로 한다. 전투 테스팅의 무제한 자원 규칙을 유지한다.
- 광물·에너지 행정의 집계 범위, 전투 페널티 대상 능력치와 합산 방식의 최종값, 캠페인 AI별 경제 연동은 [[questions]]에 남긴다.
- 수치는 `data/balance.json`의 `shortages`에서 관리한다. 상단 자원에 연속 부족이나 회복 여파를 표시하고, 상세에 활성 효과와 2단계 남은 턴을 표시한다.

## 개발용 30턴 비교

`npm run balance:shortages`를 실행한다. `--scenario=normal|recover|ignore`, `--turns=30`, `--seed=shortage-test-v1`, `--stock=energy:0,food:0`, `--population=10`, `--verbose`를 조합할 수 있다. 턴별 기록에는 생산·소모·재고·부족·패널티가 포함된다. 파일 대신 표준 출력으로 제공한다.

| 조건 | 누적 에너지 생산 | 누적 연구 생산 | 30턴 에너지 재고 / 순수지 | 회복 |
| --- | ---: | ---: | --- | --- |
| 정상 · 에너지 재고 100 | 545 | 313.5 | 129 / +2.8 | 부족 없음 |
| 복구 · −5% | 542 | 307.3 | 52.7 / +2.8 | 12턴 |
| 복구 · −10% | 539 | 301.6 | 52.2 / +2.8 | 12턴 |
| 방치 · −5% | 442.75 | 297.85 | 0 / −2.45 | 30턴 내 없음 |
| 방치 · −10% | 435.5 | 282.7 | 0 / −2.7 | 30턴 내 없음 |

- 동일 시드와 시작 시설·함선 18척을 사용했다. 복구 조건은 8턴에 에너지 특화 Lv.2를 착공하고 두 번째 작업자를 배치했다. 부족 조건은 1턴에 부족, 4턴에 군함 전투 보정 −15%가 활성화됐다. 정상 재고에서는 연쇄 부족이 없었다.
- 인구 10명·식량 재고 0의 추가 시험에서는 정상 에너지의 식량 수급이 균형이었다. 에너지 부족을 방치하면 두 패널티 값 모두 2턴부터 식량 부족 29턴이 이어졌다. 에너지 시설을 강화한 경우 에너지는 11턴에 회복했고 식량 부족은 10턴에 그쳤다.
- 단일 시드 시험은 캠페인 전반의 연쇄 부족 빈도나 최적 단가를 확정하지 않는다. −5%를 기본 TEST v1로 유지한다.
