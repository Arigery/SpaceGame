### 11.2 미확인 우주 신호 — 현재 구현 / 25% 테스트 기준


- 일반 이상현상 60%, 희귀 분류 3%, 거주 행성별 독립 65%는 변경하지 않는다. 신호는 이벤트를 생성하거나 보상을 추가하지 않는다.
- 미탐사 일반 이상현상 또는 아직 조사하지 않은 거주 가능 행성 이벤트가 실제 배정된 성계마다 별도 시드 난수로 25% 독립 판정한다. 성계당 최대 한 신호이며, 여러 이벤트가 있으면 그중 한 행성을 신호 대상으로 정한다.
- 시작 성계·완료된 이벤트는 새 신호 대상에서 제외한다. 희귀 3% 분류에는 아직 실제 콘텐츠가 없어 그것만으로 신호를 배정하지 않는다. 고대 흔적·블랙홀은 기존 표시·발견 규칙을 그대로 유지하며 이번 신호 대상에 포함하지 않는다.

- **은하지도 → 성계 내부 → 탐사 흐름**

1. 탐사선의 실제 방문으로 공개된 이웃 성계 중 신호가 있는 곳에 작은 금색 마름모와 약한 파동을 표시한다. 미공개 성계에는 표시하지 않으며 블랙홀 반대편 이름 공개만으로 원격 신호를 노출하지 않는다.
2. 미탐험 성계의 `?`는 유지한다. 호버 안내는 “미확인 신호 · 도착 후 행성을 탐사하세요”이며 행성 구성·이벤트명·보상·특성을 공개하지 않는다. 신호로 성계 진입 권한을 얻지는 않는다.
3. 탐사선이 실제로 해당 성계에 도착하면 신호가 배정된 행성에 작은 “◇ 미확인 신호” 표식을 표시한다. 이벤트 종류·수치는 계속 숨긴다.
4. 기존 개별 탐사 버튼 후 좌클릭 또는 탐사선으로 우클릭해 조사한다. 탐사 행동력은 기존 대상당 1이며 별도 신호 조사 비용·버튼·보상은 없다. 다른 행성을 조사해도 신호는 유지된다.
5. 지정 행성 탐사 시 신호를 조사 완료로 기록하고 은하지도·성계 표식을 제거한다. 원래 배정된 이상현상 또는 거주 행성 스토리 이벤트를 기존 순차 팝업으로 진행한다.

- 신호가 없어도 해당 성계 이벤트는 정상적으로 발생한다. 표식은 목적지 안내일 뿐 탐험·탐사를 대체하지 않는다.
- 배정 대상·종류·조사 완료 상태와 신호 버전을 저장한다. 기존 저장에는 아직 미탐사인 실제 이벤트만 대상으로 최초 1회 배정하며 기존 이벤트·선택·효과는 바꾸지 않는다.
- 설정은 `data/exploration.json`의 `signalChance: 0.25`, 배정·활성 조건은 `src/exploration.js`, 표식은 `src/map-ui.js`에서 관리한다. 튜토리얼은 신호를 표시하지 않는다. 파동은 약하게 반복하며 모션 감소 설정에서는 정지한다.
- 고대 흔적의 사전 공개 범위 통합, 우주의 경이·연쇄 탐사 신호 연결, AI별 신호 기록은 후속 기획이다. 현재 고대 흔적의 이름·종류 표시는 숨기지 않는다.
