## 2. 시작 조건과 행성 — 확정

| 항목 | 시작 모항성계 테라 | 이후 발견·개척한 항성계 |
| --- | --- | --- |
| 행성 구성 | 거주 가능 1 + 광물 1 + 가스 1 + 불모 1 | 기존 랜덤 생성, 성계당 3~5개 |
| 거주 행성 개척 시 인구 | 6명 | 3명 |
| 행성 중심지 | Lv.1 자동 설치 | 개척 시 Lv.1 자동 설치 |
| 중심지 기본 생산 | 식량·소비재·연구력 각각 +5/턴 | 동일 |
| 광물 행성 광산 | Lv.1 완공 상태 | Lv.0 미건설 |
| 가스 행성 채집소 | Lv.1 완공 상태 | Lv.0 미건설 |
| 불모 행성 | 개발 불가 | 개발 불가 |

- 시작 시 설치된 시설에 건설 비용이나 공사 시간을 다시 요구하지 않는다.
- 중심지 기본 생산은 작업자 배치나 구역 레벨과 무관하게 고정이다.
- 시작 성계는 항로 3개 이상에 연결되며, 직접 인접 성계 한 곳에 거주 가능 행성 최소 1개가 존재한다.
- 보장 인접 성계는 미소유 상태인 개척 대상이다.
- 신규 거주 행성의 3명 규칙은 새로 개척할 때 적용하며, 이미 저장된 행성 인구를 초기화하지 않는다.

- 시작 재고는 연구력 0, 나머지 각 100이다. 저장 자원은 0 아래로 내려가지 않는다.
- 새 캠페인은 테라에 표준 초계함 2척이 편성된 **제1 함대**와 함께 시작한다. 두 함선은 건조 대기 없이 최대 장갑·보호막, 기본 행동력 2로 배치되며 첫 턴 정산부터 유지비를 낸다. 저장 복원과 [[combattest]]의 편성은 각 화면의 기존 상태를 따른다.
