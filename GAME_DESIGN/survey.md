### 3.3 개별 탐사와 개척 — 일반 게임 기준

- 행성·고대 유적/잔해·블랙홀을 각각 탐사하며 대상당 행동력 1을 사용한다. 이미 탐사한 대상을 다시 차감하지 않는다.
- 탐사선 선택 후 대상 우클릭 → 탐사를 선택하면 해당 위치 위쪽으로 이동하고 스캔한다.
- 성계의 모든 행성을 탐사한 뒤 개척할 수 있다. 고대 오브젝트·블랙홀 탐사는 이 조건에서 제외한다. 개척선을 선택하고 중앙 항성을 우클릭하면 개척 · 행동력 1 메뉴가 나타난다. 개척선이 있는 성계에서 해당 함선을 선택하면 중앙 항성 호버 시 구체 확대와 테두리를 표시한다. 테두리는 구체에서 여유 있게 떨어뜨리고(GLB 표시 기준 외곽 inset 25.5%), 행성과 동일한 1px 두께를 사용한다. 이미 소유한 성계를 우클릭하면 개척 완료 문구를 표시한다. 기존 개척 버튼도 같은 조건을 사용한다. 개척 효과 연출은 후속 작업이다.
- 탐사 전에도 행성의 색상과 외형은 보이며 라벨에는 ‘미확인 행성’을 표시한다. 유형명과 세부 정보는 개별 탐사 후 공개한다.
- 고대 유적·잔해·블랙홀은 탐사 전에도 종류·이름과 기존 지도 표식을 표시한다.
- 일반 탐사 완료와 유적·잔해 발견은 짧은 비모달 알림과 진행 기록으로 표시한다. 이상현상은 [[anomalies]]의 확인형 결과 카드를, 거주 가능 행성 스토리는 기존 조사 화면을 사용한다.
- 최근 18개 진행 기록을 유지한다.
