# 항성계 화면

> 요약: 성계 조작·3D 모델·조명·자전·정거장·이동 연출
> 상태: 논의중
> 연관: [[movement]], [[survey]], [[interface]]

- 조작 규칙은 현재 구현 기준, 모델 크기·조명·자전 등 연출 수치는 조정 가능한 초안이다. 확정/미구현과 구분한다.
- 함대가 있는 성계로 진입할 때 해당 함대의 선택을 유지한다. 선택한 함대가 현지에 있으면 탐사선·개척선처럼 성계 화면의 빈 공간을 우클릭해 모든 소속 함선을 편대 단위로 움직인다. 이동 중 엔진 분사를 표시하며, 재배치는 AP를 사용하지 않는다. 수리 중인 함대는 이동할 수 없다. 멈춘 위치와 방향은 저장한다.
- 함선 대형은 편성에 따라 자동으로 정한다. 1척은 단독, 2~3척은 엇갈림 대형이다. 4척부터는 전함이 있거나 호위함이 절반 이상이면 호위 대형, 그 외 중순양함·구축함이 합쳐 절반 이상이면 전열 대형, 나머지는 쐐기 대형을 사용한다. 중순양함·호위함은 앞쪽, 전함은 후방, 초계함은 바깥쪽을 우선한다.
- 성계 내 우클릭 이동은 출발 방향에서 이어지는 곡선을 따른다. 함선은 이동하면서 방향을 바꾸고 편대 간격을 유지한다. 여러 함대가 함께 움직이면 함대 간 간격을 둔 쐐기로 도착한다. 전투 테스팅의 군단 배지를 누르면 해당 성계에 있는 소속 함대를 함께 선택한다.
- 함대 이동 모드에서 강조된 인접 항로나 은하 지도의 목적지를 좌클릭하면 워프 충전·이탈·진입·감속을 연출한다. 여러 출발지가 포함된 공동 이동은 첫 출발지를 보여 주고, 모든 편대가 자기 항로 방향에서 도착하는 장면을 표시한다. 빠른 이동 또는 동작 줄이기 설정은 연출을 생략한다. AP·경로·공동 교전은 [[fleets]]를 따른다.

### 8.2 항성계 화면과 이동 연출 — 일반 게임 기준

- 함선 이동 버튼의 표시 문구는 항상 '이동'이다. 은하 지도에서는 기존 이동·개별 탐사 동작을 유지한다.
- 항성계에서 '이동'을 누르면 선택 함선이 실제 위치한 성계의 이동 가능한 삼각형 자체에 1.2px 외곽선과 밝은 발광 효과를 표시하고(별도 원형 테두리 없음) 좌클릭으로 이동한다. 일반 항로는 밝은 금색, 개척 연결 항로는 밝은 청록색으로 구분하며, 호버 시 테두리 색을 유지하면서 삼각형을 더 밝게 표시한다. 이동 모드가 아닐 때의 삼각형 좌클릭은 기존 성계 화면 열기다.
- '개별 탐사'를 누르면 해당 성계의 미탐사 행성·오브젝트 중 행동력으로 탐사 가능한 대상을 강조하고 좌클릭으로 탐사한다. 기본 좌클릭 상세 보기와 우클릭 명령은 유지한다.
- 항성계의 개척 버튼은 대상 선택 모드로 전환한다. 개척선이 현재 성계에 있고 행동력 1 이상·개척 조건 충족일 때만 중앙 항성을 강조하며 좌클릭으로 개척한다. 기존 우클릭 개척과 은하 지도 개척 버튼 동작은 유지한다.
- 이동·탐사·개척 선택 모드는 서로 배타적이다. 활성 버튼·대상·안내 문구로 표시하고 같은 버튼 또는 Esc로 취소한다. 함선 변경·선택 해제·다른 화면 진입 시 탐사 모드를 해제하며, 명령 실행 후에도 해제한다.
- 거주 행성 근처의 조선소 표식을 클릭하면 시설 관리 화면을 연다. 개척선의 행성 우클릭 메뉴에서 궤도 조선소 건설을 시작할 수 있다. [[shipyards]]

- 항성계는 상단 공통 자원 UI 아래 화면을 가득 채운다. 바깥 검은 패널·상세 안내 문구·하단 범례·상단 은하 지도 복귀 버튼을 숨기고, 성계 이름만 상단 중앙에 표시한다. 은하 지도 복귀는 왼쪽 은하 지도 탐색 버튼을 사용한다.

- 개척된 성계에는 중앙 항성을 공전하는 사용자 제공 티타늄 우주정거장 GLB를 표시한다. 원본은 `assets/stations/titanium_colony_station.glb`로 관리한다. 부모 노드의 위치·회전·크기를 반영해 링과 선체를 조립하고, 재질 색상·발광과 기울어진 시점을 적용한다. GLB의 링 회전 키프레임을 읽어 30초 주기로 링만 회전시킨다. 정거장 전체는 항성 중심의 기울어진 타원 궤도를 공전한다. 공전 초안은 5분, 가로 반경 110, 세로 비율 0.57이며 `data/balance.json`의 `stationAppearance`에서 조정한다. 공전 위치는 requestAnimationFrame과 소수점 translate3d로 매 화면 프레임 갱신하며, 모델·링 렌더링은 약 15fps로 분리한다. 해당 성계가 보일 때만 링·공전을 진행하고 화면 이탈·창 숨김 시 정지 후 복귀 시 재개한다. 각도는 세션 내 시각 상태로 관리한다. 조명 점멸 채널과 완전한 PBR 재질은 적용하지 않는다. HTML 직접 실행을 위해 모델을 빌드에 포함한다.

- 어두운 우주 배경에 노란 항성, 파란 거주 가능 행성, 보라 가스 행성, 붉은 광물 행성, 회색 불모 행성을 배치한다.
- 모든 항성계 화면의 배경은 제공된 `Map_Background_1_DEC.png`를 `assets/backgrounds/system-map.png`에 보관해 공통으로 사용한다. 배경은 항성·행성·함선이 움직이는 층 바깥의 화면 영역에 고정하여 확대·축소와 드래그에도 위치·크기가 바뀌지 않는다. 기존 확대되는 장식 별 배경은 숨긴다.
- 기울어진 2.5D 시점에서 구체와 GLB 탐사선·개척선 메시를 렌더링한다. 함선의 궤도면 방향을 카메라에 투영하며 이동 후에도 그 방향을 유지한다.
- 항성은 `golden_star.glb`, 거주 가능·가스·광물·불모 행성은 각각 제공된 `habitable_planet.glb`, `gas_planet.glb`, `mineral_planet.glb`, `barren_planet.glb`의 메시와 내장 표면 텍스처로 표시한다. 원본은 `assets/celestial/`에서 관리하고 HTML 직접 실행을 위해 빌드에 포함한다. 공용 WebGL 렌더러와 이미지 캐시를 사용하며 금속성·거칠기 등 전체 PBR 재질 대신 간소화한 조명과 항성 발광을 적용한다.
- 행성 호버·키보드 포커스 시 기존의 소폭 확대와 함께 모델 바깥에 유형별 색상의 1px 원형 테두리와 은은한 빛을 표시한다. 개척선으로 상호작용 가능한 항성도 확대된 모델과 겹치지 않는 원형 테두리로 강조한다.
- 행성 표면은 중앙 항성 방향으로 조명하며 기울어진 궤도면의 깊이를 반영한다. 구형 메시의 부드러운 방사형 법선과 완만한 명암 경계를 사용하며 반대쪽에도 환경광을 남긴다. 같은 유형이라도 위치별 조명을 별도로 전달하고, 자전 및 텍스처 로딩 후에도 해당 방향을 유지한다.
- 공통 렌더링 초안은 `src/models.js`의 `PLANET_LOOK`에서 관리한다: 환경광 0.025, 확산광 0.92, 채도 90%, `#0D1526` Soft Light 혼합 18%. 조명은 선형 색 공간에서 계산한다. 항성도 동일한 네이비 색보정 18%를 적용하되 행성용 방향성 그림자에서는 제외해 황금빛 발광을 유지하고, 항성계 배경에도 동일한 네이비 색상을 약하게 혼합한다.
- 거주 가능 행성에는 청색, 가스 행성에는 보라색, 광물 행성에는 붉은색의 넓고 부드러운 가장자리 산란광과 흐린 외곽 대기층을 적용한다. 불모 행성에는 대기광을 적용하지 않는다. 금속성 반사·강한 정반사 하이라이트 없이 원본 표면 텍스처를 유지한다. 행성 표면에는 0.35px, 항성 표면에는 0.6px의 약한 흐림을 적용해 질감을 부드럽게 한다. 항성의 황금빛 번짐은 두 층으로 부드럽게 표현하고, 호버 테두리 강조를 유지한다.
- 일반 게임의 행성은 공전 없이 제자리 자전한다. 크기와 유형별 자전 주기를 적용한다(아래 표). 해당 항성계 화면에서만 약 15fps로 갱신하며, 다른 화면·항성계 또는 숨겨진 창에서는 멈춘다. 돌아오면 각도를 이어가고 항성 방향의 조명·그림자는 고정한다. 정점 데이터와 캔버스를 재사용하고 회전은 GPU에서 계산한다. 자전 각도는 현재 플레이 세션의 시각 상태로 관리한다. 항성 자체와 튜토리얼에는 자전을 추가하지 않는다.
- 일반 맵 생성 시 각 행성의 크기를 소형·중형·대형 중 동일 확률로 배정한다. 크기 배정은 독립된 시드 난수를 사용해 기존 성계·행성 구성에 영향을 주지 않는다. 현재 표시 크기를 중형(1배)으로 두고 소형은 0.8배, 대형은 1.2배이며 대기광과 호버 테두리도 함께 조정한다. 크기는 `sizeClass`로 저장하고, 이전 저장 파일의 누락·잘못된 값은 중형으로 처리한다. 인구·생산량 등 게임 수치에는 영향을 주지 않는다. 튜토리얼은 중형을 유지한다.
- 설정은 `data/balance.json`의 `planetAppearance`에서 관리한다. 아래 주기는 과학 법칙이 아닌 시각적 다양성을 위한 연출 설정이며, 불모 행성은 광물보다 1분 느리게 설정한다.

| 유형 | 대형 | 중형 | 소형 |
| --- | ---: | ---: | ---: |
| 가스 | 1분 | 2분 | 3분 |
| 거주 가능 | 2분 | 3분 | 4분 |
| 광물 | 3분 | 4분 | 5분 |
| 불모 | 4분 | 5분 | 6분 |

- 기본 탐사선 함체는 17.64px다. 구체 캔버스 배율은 행성 0.612, 항성 0.441이다(직전 크기 대비 각각 0.85배, 0.7배). 대기광과 호버 테두리도 축소 비율에 맞춘다. 이는 현재 시각 조정값이다.
- 함선은 선택 여부와 관계없이 존재하는 성계에 표시한다. 작은 위치 링을 제공하고 선택·호버·키보드 포커스 시 링과 이름을 강조한다.
- 휠은 마우스 위치 중심으로 최대 12배 확대한다. 최소 배율은 성계 전체가 보이는 수준이다. 좌클릭 드래그로 확대 화면을 이동하고, 축소 시 위치를 경계 안으로 보정한다.
- 외곽의 삼각형은 배경·테두리 없이 궤도면 방향으로 기울여 표시한다. 크기는 기존 22px의 1.25배인 27.5px이며 일반 항로는 금속빛 금색, 양쪽 모두 개척된 연결 항로는 청록색으로 구분한다. 호버·키보드 포커스 시 밝게 강조하고 툴팁에 항로 종류와 기본 구간 행동력 비용(일반 1, 개척 연결 0.3)을 표시한다. 호버 시 이웃 이름 또는 진입 안내를 표시한다. 이름이 밝혀진 성계는 좌클릭으로 열며, 우클릭은 선택 함선의 이동 명령을 제공한다.
- 탐사 완료 행성은 평소 유형 한 줄만 표시한다. 행성 유형·이름·시설 정보의 배경은 항성 이름처럼 투명하게 하고, 글자 그림자로 가독성을 보완한다. 호버·키보드 포커스 시 이름과 시설·건설 상태를 보여주고, 좌클릭으로 상세·관리 화면을 연다. 건설 중이면 유형 옆에 작은 공사 표시를 붙인다.
- 미탐사 행성은 색상 구체와 '미확인 행성' 문구만 표시한다. 번호·물음표·유형·상태 문구를 추가하지 않는다.
- 고대 오브젝트와 블랙홀은 탐사 전 점선·물음표, 완료 후 실선·체크·은은한 빛으로 구분하며 각각 주황·보라 계열을 유지한다.
- 일반 이동은 워프 준비 후 출발 방향의 도착 외곽에 나타나 중앙으로 이동한다. 성계 내 이동은 날개 아래 좌우 엔진 두 곳, 워프 준비는 후방 중앙 엔진에서 배기를 표시한다.
- 스캔은 함선 아래로 옅은 원뿔형 빛을 비추고 타원형 소나 파동이 하강하며 넓어지는 방식이다.
- 빠른 이동 옵션은 즉시 이동을 표시한다. 연출 중 명령 입력을 잠가 중복 실행을 방지한다.
- GLB 원본은 assets/ships/exploration_ship_NX02.glb와 assets/ships/space_colony_ship.glb에 보관하며 game.js에 포함하므로 HTML 직접 실행으로 로드된다. 개척선의 내장 색상 텍스처를 사용하며 금속·거칠기·범프 등의 정밀 재질은 현재 간이 조명에서 생략한다.
- 튜토리얼은 기존 탐사·건물 화면과 안내 순서를 사용한다. 일반 게임의 개척선은 탐사선과 같은 내부 이동·항로 워프·블랙홀 이동 연출을 사용한다. 소유한 성계의 중앙 항성 주위를 공전하는 GLB 우주정거장을 표시한다.
