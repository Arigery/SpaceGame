# 검증 이력

> 요약: 기존 검사 날짜·범위·수치와 실제 화면 검증의 한계
> 상태: 확정
> 연관: [[data]], [[workflow]]


- 기존 문서에 기록된 2차 구현 당시의 검증 결과는 코드·로직 검사 16개 통과다. 초기 조건, 비용 차감, 동적 생산력, 5/8/12턴, 유지비, 30턴 수급, 저장 복원 및 20개 시드 지도 보존을 확인했다.
- 실제 브라우저 검사는 사용자의 별도 요청이 있을 때 진행한다.
- 검증 후 임시 테스트 코드·출력 이미지·임시 프로필·일회성 스크립트를 정리한다. `tests/`의 회귀 검사와 빌드 도구는 유지한다.

### 탐험 개선 1~5단계

- `npm run build`, `npm run check`, `npm test` 131개 통과. 고정 시드 100개로 이상현상 상한, 연쇄 배치 및 지역형 경이 연결성을 확인했다. 이상현상 검증 세트에서 적대 세력은 78개 지도에 125건, 탐사선 파괴는 21건이었다. 각 은하에서 적대 2건·파괴 1건의 상한을 지켰다.
- 조사 기술에 따른 미확인 신호 공개, 최초 발견·조사 문명 소유권, 민간선 재생산, 경이 자원 정산, 유적·조선소 진행량, 저장 복원 및 결과 카드 확인 후 중복 지급 방지를 검증했다. 브라우저의 화면과 조작은 실행하지 않았다.

### 과학 승리와 궤도 착공

- 빌드와 코드 검사, 자동 테스트 133개가 통과했다. 유적 조사·연구·재고 조건, 현지 개척선 우클릭 착공, 착공비 1회 차감, 개척선 이동 후 고정 12턴 진행, 저장 복원을 확인했다.
- 완공 직전 성계가 점령되면 공사와 진행도를 제거하고 착공비를 소모한 상태로 유지하는지 검증했다. 탈환한 성계나 다른 소유 행성에서는 처음부터 새로 착공한다. 검증 범위는 코드와 자동 테스트다.

- [[combatui]] · 전투 중 양측 요약과 후퇴 선택 화면을 확인했다. 함대·설계·조선소에서는 탭 간 창 크기, 편제 36/50의 배치 30·증원 6 표시, 모듈 교체에 따른 전력 갱신과 생산·수리 동시 표시를 확인했다.
- [[surface]] · 지표 슬롯 9개와 건설 표시, 건설·상세 창의 동일한 크기를 확인했다. 중심지에 1명을 배치하면 다음 턴 공사량이 6에서 7로 갱신됐다.
- [[researchscreen]] · 5개 분야·I~V단계·연구 가능과 잠김 상세를 확인했다. 1280×720에서 잠긴 행성 조사 기술 I과 선행 기술 행성 탐사 기록의 이름이 겹치지 않는 것을 추가 확인했다.
- [[saves]] · 새 게임 시작, 기존 형식의 5개 슬롯 불러오기, 빈 슬롯과 최근 저장 표시, 새로고침 후 빠른 이동 유지 및 게임 내 설정 동기화를 확인했다.

### 건설·유지비·자원 수급 시험

- 실제 착공·턴 정산으로 비교했다. 모두 인구 10인 모행성(주거 시설 Lv.1 사전 배치), 신규 거주 행성 인구 3에서 시작했다. 개척 시점과 투자 순서는 시험에서 지정했다. 탐사 보상·전투와 미구현 생산 재료는 제외했다. 연구력은 평가 대상에서 제외했다.
- 자원 순수지는 일회성 착공비·함선 주문비를 제외하고 해당 턴에 적용한 값이다. 착공 차단은 자원 부족 때문에 막힌 주문·턴을 세며, 이전 공사나 선행 단계 대기는 포함하지 않는다. 모든 비교에서 정산으로 충당하지 못한 소비는 0이었다.
