# 지역형 우주의 경이

> 요약: 항로로 연결된 경이 4종과 성계 소유권 기반 효과
> 상태: 확정
> 연관: [[discoveries]], [[economy]], [[movement]], [[saves]]

- 아래 효과는 최초 구현 시험 수치이며 `data/balance.json`에서 관리한다.
- 새 은하에는 종류별 1지역을 배정한다. 지역마다 일반 항로로 연결된 2~4성계가 속하며 지역끼리 겹치지 않는다. 시작 성계에서 최소 3구간 떨어지고 초기 개척 보장 성계는 제외한다.
- 가능한 경우 시작 문명 두 곳과 거리가 비슷한 성계를 포함한 지역을 우선한다. 관문·고대 흔적·블랙홀은 우선 피한다. 해당 배치 조건에서 후보를 구성할 수 없으면 중복 회피만 완화하고 사유를 저장한다.
- 지역 첫 방문 문명에 연구력 10을 즉시 한 번 지급한다. 영향권의 성계별 효과는 해당 성계를 소유한 문명에 적용되며, 점령 시 해당 성계의 효과만 이전된다. 경이는 이동·파괴되지 않는다.

| 경이 | 지역 배치 조건 | 소유 성계 효과 |
| --- | --- | --- |
| 공명 성운 | 거주 가능 행성 성계 1곳 이상 | 연구 생산 +5%. 일반 항로 거리 2 이내의 지도 공개·미방문 성계 행성 유형별 개수를 관측 |
| 결정의 바다 | 광물 행성 성계 2곳 이상 | 광산 광물 생산 +5%. 가동 광산이 하나라도 있으면 해당 성계에서 신소재 +1/턴 |
| 중력의 회랑 | 지역 내 일반 항로 | 같은 문명이 양끝을 소유한 지역 내부 항로에서 행동력 −0.05, 최소 0.25 |
| 영원의 빛 | 거주 가능 행성 성계 1곳 이상 | 에너지 +8/턴, 거주 행성 건물 에너지 유지비 −10% |

- 생산 보정은 기존 생산 보정군에 더한다. 신소재와 에너지 고정 지급에는 생산 배율을 적용하지 않는다. 각 지역 전체에서는 신소재 최대 +4/턴, 에너지 최대 +32/턴이다. 함선·조선소·관문·자원 행성 시설 유지비는 할인 대상에서 제외한다.
- 공명 성운은 지도 공개 범위나 방문·탐사 상태를 바꾸지 않는다. 소유권을 잃으면 새 관측은 멈추고 기존 관측 정보는 남는다. 중력의 회랑은 블랙홀·관문 이동에 적용하지 않는다.
- 지도에는 공개된 성계에만 원과 연결 구간을 표시한다. 성계 내부에서는 이름과 소유 효과를 짧은 표식과 호버로 보여준다. 지역 구성과 최초 발견·관측 정보는 저장하며 이전 저장에는 새 경이 지역을 삽입하지 않는다.
