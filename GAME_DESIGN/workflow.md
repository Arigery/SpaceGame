## 현재 문서 운영
- 기획의 기준은 이 폴더의 주제별 문서다. 진입점은 [[INDEX]]다.
- 먼저 [[INDEX]], 다음 작업 주제, 필요한 연관 문서만 읽는다. 전체 파일 일괄 열람은 문서 전면 이관 등 필요한 작업에만 한정한다.
- 상태는 문서 전체의 성숙도다. 확정 항목과 테스트·미결정 항목이 섞이면 논의중으로 표시하되 본문의 기존 확정 표기를 유지한다.
- 확정/논의중/폐기는 구현 여부와 다르다. 본문의 현재 적용·미구현·1차/2차 테스트 표기를 보존한다.
- 문서명은 내용 기반 영문 소문자, INDEX.md만 예외다. 하위 폴더 없이 문서당 200줄 이하를 유지하며 짧은 문서를 억지로 늘리지 않는다.
- 변경 이유는 [[decisions]]에 한 줄로 기록한다. 기존 날짜별 결정 이력은 [루트 DECISIONS.md](../DECISIONS.md)를 참조하며 중복 관리하지 않는다.
- 위키 링크는 파일명 기준이다. GitHub에서 탐색할 때는 [[INDEX]]의 일반 Markdown 링크도 함께 이용한다.
