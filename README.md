# 우주 문명 시뮬레이션

미지의 성계를 탐사하고 행성을 개척하며, 한정된 인구와 자원을 배분해 거점을 성장시키는 턴 기반 우주 전략 시뮬레이션 프로토타입입니다.

게임을 직접 기획하고 개발해 실제로 출시하는 경험을 목표로 합니다. 탐험·확장·행성 운영을 연결하고, 플레이 피드백을 바탕으로 조작과 게임 규칙을 개선해 나가고 있습니다.

## 브라우저에서 바로 플레이

https://arigery.github.io/SpaceGame/

현재 시스템을 살펴보려면 **새 게임**으로 시작하세요. 함선을 선택해 이동하고, 성계 내부에서는 탐사선의 개별 탐사 버튼을 누르고 강조된 대상을 좌클릭하거나, 대상을 우클릭해 탐사할 수 있습니다. 행성 관리는 좌클릭, 자원 정산과 공사 진행은 다음 턴 버튼을 사용합니다.

전투를 바로 시험하려면 메인 메뉴의 **전투 테스팅**을 여세요. 양측 함대·설계와 AI 태세를 정하고 **양측 편성 확인 → 플레이 시작**을 누르면 지도 양쪽 끝에서 출발합니다. 네 성계의 조선소는 완공 상태이며, 무제한 자원으로 생산·수리·증원을 시험하고 **데이터** 탭에서 누적 비용을 확인할 수 있습니다. [전투 테스팅 안내](GAME_DESIGN/combattest.md)

튜토리얼은 현재 비활성화되어 있습니다. 메인 메뉴에는 버튼만 표시하며, 주요 시스템 확정 후 최신 규칙과 조작에 맞춰 개편할 예정입니다.

## 핵심 플레이 흐름

**성계 탐험 → 개별 대상 탐사 → 개척 → 인구 배치와 시설 건설 → 자원 확보 → 다음 성계로 확장**

- 탐사선의 행동력을 이동과 행성·오브젝트 탐사에 배분합니다.
- 탐사선이 방문한 성계에 개척선을 보내고, 모든 행성의 탐사를 마치면 개척 버튼을 누른 뒤 중앙 항성을 좌클릭하거나 우클릭 메뉴로 개척합니다.
- 거주 행성에서는 인구를 시설에 배치하고, 광물·가스 행성에서는 채굴 시설을 개발합니다.
- 시설 투자 비용과 유지비, 완공까지의 시간을 확인하며 확장 순서를 선택합니다.

## 기획에서 다루는 선택

아래는 현재 규칙을 통해 검토하는 설계 관점입니다. 플레이 테스트로 확인할 질문을 함께 기록합니다.

| 설계 주제 | 현재 적용한 구조 | 확인할 플레이 경험 |
| --- | --- | --- |
| 탐험의 순서 | 이동·개별 탐사가 행동력을 공유하고, 모든 행성 탐사 후 개척 가능 | 주변을 더 탐색할지 한 성계의 탐사를 마칠지 선택하는가? |
| 인구 배분 | 중심지 배치는 공사 생산력을 높이고 특화 건물 배치는 자원 생산에 기여 | 공사 단축과 당장의 자원 생산을 비교하는가? |
| 행성별 개발 | 거주 행성은 생산력 누적 공사, 광물·가스 행성은 고정 기간 공사 | 인구 기반 성장과 채굴 투자의 차이를 이해하고 활용하는가? |
| 확장과 투자 | 착공 비용 선지불, 가동 시설 유지비, 개척 항로 이동 비용 감소 | 확장 속도와 기존 거점에 대한 투자 사이에 선택이 생기는가? |
| 정보 전달 | 미확인·탐사 완료 상태, 비용·공사 예상 기간·자원 내역 표시 | 다음 행동의 조건과 경제적 결과를 예측할 수 있는가? |

## 현재 구현 범위

- 시드 기반 은하 생성, 항로 이동과 개척 항로의 행동력 할인
- 행성·고대 오브젝트·블랙홀 개별 탐사와 블랙홀 이동
- 성계 단위 이상현상 60%·17종 이벤트와 거주 가능 행성별 독립 65% 탐험 이벤트
- 환경별 거주 행성 스토리 80종, 조사 방향·위험도 선택과 행성별 영구 특성
- 금색 프레임의 이벤트 창·일러스트 공간과 단계별 호버 정보 공개
- 실제 미탐사 이벤트 성계의 25%에 사전 신호 표시, 도착 후 대상 행성 탐사 안내
- 좌측 승리 메뉴에서 점수·과학·번영·연합·패권의 기획 개요 확인
- 5분야·기원~V단계의 방사형 연구 구조와 임시 기술·미설계 슬롯, 재고 연구력 투입·진행 보존·부속 해금과 경제/탐험 보정
- 6종 자원, 인구 성장·배치, 공용·특화·부속 시설과 공사·유지비
- 2.5D 성계와 탐사선·개척선 모델, 이동·스캔 연출, 개척 정거장과 지표 건물 관리 화면
- 일러스트 메인 메뉴·고정 우주 배경과 범위가 제한된 은하 지도
- 텍스처가 포함된 항성·4종 행성 GLB, 항성 방향 조명·대기광 및 3단계 크기·자전
- 상단 자원·메뉴와 왼쪽 탐색 버튼, 좌측 하단 함선 패널 및 이동·탐사·개척 대상 선택
- 티타늄 우주정거장 GLB, 링 회전과 항성 중심 공전
- 5종 전투 함급, 모듈 설계·연구 해금, 함대 편성과 공동 이동
- 궤도 조선소 건설·직접 생산·함대 수리, 편제 예약과 자동 증원, 적대 성계 점령과 조선소 인수
- 자동 함대 전투와 휠 확대, 단거리 후퇴와 긴급 워프
- 군단 펼침 목록과 함급별 와이어프레임, 편제·증원 막대와 보호막·장갑 게이지, 건조·유지비의 공통 자원 아이콘
- 브라우저 저장 5개 슬롯과 기존 저장 데이터 호환 처리

목표 플레이 시간은 3~5시간이며 초기 건설 필요 생산력을 낮췄습니다. 실제 플레이 시간과 군함·전투 밸런스는 테스트 중입니다. 캠페인 AI 전략, 외교, 항복·봉쇄, 유지비 부족 처리, 연구 상세화와 실제 승리 판정은 후속 범위입니다. 승리 화면은 현재 기획 안내를 제공합니다. [게임 기획 색인](GAME_DESIGN/INDEX.md)

## 제작 역할과 개선 과정

기획자는 규칙과 수치의 방향을 정하고 변경을 요청하며, 직접 플레이해 화면·조작과 체감을 확인합니다. AI 개발 도구를 활용해 구현, 코드·데이터 검사, 문서 정리를 진행합니다. 탐사선·개척선·항성·행성 모델과 메인 메뉴·지도 배경은 사용자 제공 에셋을 사용합니다.

| 단계 | 적용한 변화 | 관련 기록 |
| --- | --- | --- |
| 건설 경제 | 인구 기반 생산력 공사와 채굴 고정 기간, 비용·유지비 적용 | D-008 |
| 성장·이동 조정 | 특화 생산과 부속 보너스, 개척 항로 이동 할인 | D-010 |
| 초기 입문 안내 | 고정 지도에서 건설·배치·탐사·개척 실습 | D-012 |
| 탐험·운영 화면 확장 | 개별 탐사, 블랙홀 정보 공개, 2.5D 성계와 지표 관리 | D-013, E-004 |
| 우주 화면과 행성 연출 | 고정 배경, GLB 표면·방향성 조명, 크기별 자전과 저장 호환 | D-016, D-017 |
| 정거장과 명령 UI | 링 회전·부드러운 공전, 통합 패널·아이콘, 버튼 선택과 우클릭 병행 | D-018, D-019 |
| 탐험 목적지와 승리 안내 | 미확인 신호 25%와 5종 승리 개요 화면 | D-025, D-026 |
| 성장 속도와 탐험 선택 | 초기 건설 단축, 일반 이상현상과 환경별 조사 스토리·영구 특성 | D-020, D-021, D-022, D-023 |
| 개척선과 상호작용 | 방문 성계 이동 제한, 중앙 항성 개척, 정거장 표시·함선 방향·선택 유지 | D-014 |

변경 내용과 근거는 [결정 기록](DECISIONS.md)에서 확인할 수 있습니다. 현재까지의 코드 검사와 실제 플레이 평가를 구분하며, 플레이 평가 결과는 확인 후 기록할 예정입니다.
