# 우주 문명 시뮬레이션

미지의 성계를 탐험하고 행성을 개척하는 브라우저 기반 턴제 우주 4X 게임입니다. 탐사에서 얻은 정보로 다음 확장지를 고르고, 행성의 인구와 자원을 배분해 제국을 성장시킵니다.

## 브라우저에서 플레이

**[게임 시작](https://arigery.github.io/SpaceGame/)**

- **새 게임**으로 시작하면 모성계 테라에서 탐사선·개척선과 초계함 2척으로 구성된 기본 함대를 운용합니다.
- **전투 테스팅**에서는 양측 함대를 편성하고 자동 전투, 후퇴, 조선소 생산·수리·증원을 시험할 수 있습니다. [전투 테스팅 안내](GAME_DESIGN/combattest.md)
- 로컬에서는 저장소를 내려받고 브라우저에서 `index.html`을 열면 됩니다.

## 핵심 플레이 흐름

**탐험 → 탐사 → 개척 → 행성 운영 → 확장**

1. 탐사선으로 이웃 성계를 방문하고 행성·이상현상·고대 유적을 조사합니다.
2. 행성 탐사를 마친 성계에 개척선을 보내 거점을 확보합니다.
3. 거주 행성에 인구를 배치해 건설과 자원 생산을 늘리고, 광물·가스 행성에 채굴 시설을 세웁니다.
4. 연구와 조선소에 투자해 함대를 편성하고, 다음에 탐험하거나 확보할 성계를 선택합니다.

## 개발 현황

개별 행성 탐사, 이상현상 결과 카드, 연쇄 탐사, 지역형 우주의 경이, 고대 유적을 이용할 수 있습니다. 관문을 건설해 함선을 이동시키거나 번영 승리에 도전할 수 있습니다. 저장 슬롯은 5개이며 과학 최종 프로젝트와 외교는 후속 개발 범위입니다.

게임을 직접 기획·개발해 출시하고, 플레이 피드백을 바탕으로 개선하는 것이 목표입니다.
